# 카드 뒷면

카드 한 장의 뒷면이다. **게임에 한 장뿐이다** — 카드마다 다르지 않다.

```
back_of_axiom.png        952x1540 (세로/가로 1.615, 카드 앞면 큰 것과 같은 크기)
```

## 여기 있는 이유

카드 뒷면은 **화면에 딸린 것이 아니라 카드에 딸린 것**이다. 전투와 상점 뽑기가 함께 쓰고,
앞으로 덱과 도감도 쓴다. 그래서 `card_race` `card_kinds` 와 같은 자리에 둔다 —
`shop/` 아래 두면 전투가 상점 자원을 가리키게 된다.

**번호가 아니라 이름을 쓴다.** `card_race/1.png` `card_kinds/4.png` 가 번호인 것은 그 번호가
종족과 종류를 뜻하고, 번호로 찾기 때문이다. 뒷면은 한 장뿐이라 번호가 아무것도 안 뜻한다.

나중에 카드 스킨이 생기면 (`shop/card_skin_button` 과 `card_skin_popup` 이 이미 있다)
`back_of_<스킨>.png` 로 늘어난다. 그때 이름이 어느 스킨인지 말해 준다 —
`0.png` `1.png` 는 파일을 열어 봐야 안다.

## 지금 비어 있다

그림이 없으면 **상점 뽑기가 값으로 그린다** — 어두운 남빛 바탕, 금테, 가운데 팔각별,
점선 고리. 그림을 넣으면 그림을 쓴다. 코드는 안 바뀐다.

바꾸는 곳은 한 줄이다.

```ts
// src/card/shape.ts
export const CARD_BACK_IMAGE: string | null = 'resource/card_back/back_of_axiom.png';
```

## 크기를 한 벌로 두는 이유

카드 앞면은 쓰는 곳마다 따로 있다 — 전투 660x1066, 내 카드 952x1540. 큰 그림을 작게
줄여 그리면 지글거리기 때문이다 (이 프로젝트는 밉맵을 끈다).

뒷면은 **지금 쓰는 곳이 상점 뽑기뿐이고 거기는 브라우저가 그린다** (DOM). 브라우저는 잘
줄이므로 큰 것 한 장으로 충분하다.

전투에서 뒷면이 필요해지면(멀리건, 1대1 대전) 그때 실제로 지글거리는지 보고 작은 것을
더한다. **미리 두 벌 만들면 한쪽만 고쳐진다.**
