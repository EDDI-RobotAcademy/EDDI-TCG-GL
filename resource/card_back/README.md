# 카드 뒷면

카드 한 장의 뒷면이다. **게임에 한 장뿐이다** — 카드마다 다르지 않다.

```
card_back_image.png    952x1540 (판) 안에 927x1501 (카드), 둘레 여백은 투명
```

## 여기 있는 이유

카드 뒷면은 **화면에 딸린 것이 아니라 카드에 딸린 것**이다. 전투와 상점 뽑기가 함께 쓰고,
앞으로 덱과 도감도 쓴다. 그래서 `card_race` `card_kinds` 와 같은 자리에 둔다 —
`shop/` 아래 두면 전투가 상점 자원을 가리키게 된다.

**파일 이름이 이것을 가리키는 값의 이름과 같다.** `CARD_BACK_IMAGE` → `card_back_image.png`.
둘 중 어느 쪽으로 찾아도 다른 쪽이 같이 나온다.

번호를 안 쓴 것은 `card_race/1.png` 와 사정이 달라서다. 거기 번호는 종족을 뜻하고 번호로
찾는다. 뒷면은 한 장뿐이라 번호가 아무것도 안 뜻한다.

카드 스킨이 생기면 (`shop/card_skin_button` 과 `card_skin_popup` 이 이미 있다) 그때
스킨 이름을 붙인 파일이 옆에 늘어난다.

## 크기는 카드 앞면과 같은 규격이다

카드 앞면 100장이 전부 같은 규격이다. 재 봤다.

```
952 x 1540  판     ← 그림 파일 크기
 927 x 1501 카드   ← 실제 카드. 둘레 1.3% 는 투명한 여백
```

**그림 파일 크기가 카드 크기가 아니다.** 뒷면도 같은 규격이라야 뒤집을 때 크기가 안 변한다.

원본에서 다시 만들려면:

```
ffmpeg -i card_back_image_source.png -vf \
  "crop=978:1486:23:6,pad=978:1583:0:48:0x080807,scale=927:1501,pad=952:1540:12:20:color=0x00000000" \
  -pix_fmt rgba card_back_image.png
```

## 비어 있을 때

그림이 없으면 **상점 뽑기가 값으로 그린다** — 어두운 남빛 바탕, 금테, 가운데 팔각별,
점선 고리. 그림을 넣으면 그림을 쓴다. 코드는 안 바뀐다.

바꾸는 곳은 한 줄이다.

```ts
// src/card/shape.ts
export const CARD_BACK_IMAGE: string | null = 'resource/card_back/card_back_image.png';
```
