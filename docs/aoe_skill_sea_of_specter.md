# 망령의 바다 (Sea of Specter) — 광역기 구현

## Success Criteria

### 1. 스킬 빌드업 (에너지 수집)

#### 1-1. 카드 이동
- [x] 시전 카드가 스킬 패널 위치(화면 하단 중앙, `x=0, y=(0.5-0.78221649)*h`)로 800ms에 걸쳐 이동
- [x] 이동 중 카드의 z값이 `origPos.z + 1`로 올라가 다른 카드 위에 렌더링

#### 1-2. 어둠 응축 오라 (createDarkCondenseAura)
- [x] 시전자 중심에서 `cardW * 10` 크기의 어둠이 소용돌이치며 응축
- [x] 4겹 레이어 구성: 나선형 연기(warped FBM 2겹) + 어둠 촉수(warped FBM 2겹) + 맥동 코어(이중 sin) + 입자 줄무늬(6줄)
- [x] 5옥타브 FBM + warped FBM(자기 참조 노이즈)으로 유기적 표현
- [x] 밀도 높은 곳에서 보라빛 발광 `(0.06, 0.0, 0.12)`
- [x] buildup 변수로 시간에 따라 점진적으로 강해짐 (`min(t * 0.6, 1.0)`)
- [x] 알파 최대 0.92, 원형 edgeFade 마스크(`smoothstep(0.85, 1.0, dist)`)로 사각형 경계 제거

#### 1-3. 화면 가장자리 어둠 (createEdgeDarken)
- [x] `max(w, h) * 2` 크기의 전체 화면 오버레이
- [x] 화면 가장자리에서 안쪽으로 어둠이 시간에 따라 침식 (`progress = min(t * 0.5, 0.8)`)
- [x] 비네트 효과 — 화면 모서리가 거의 검정으로 변함 (배율 0.7)
- [x] 어둠 맥동 — 이중 sin(`t*3.0`, `t*5.0`)으로 어둠이 숨 쉬듯 팽창/수축
- [x] 알파 최대 0.9

#### 1-4. 마법진 (createMagicCircle)
- [x] 시전자 아래에 `cardW * 3` 크기의 회전하는 마법진
- [x] 이중 링 (반경 0.55~0.65, 0.75~0.85) + 룬 패턴 (8각 + 12각 회전)
- [x] 내부 발광 + sin 맥동으로 밝기 변화
- [x] 시간에 따라 scale 0→1로 확대 등장
- [x] `rotation.z = t * 0.5`로 지속 회전

#### 1-5. 냉기 파동 (spawnColdWavePulse)
- [x] 시전자에서 바깥으로 퍼지는 파란 빛 링 (Additive Blending)
- [x] 총 7회 발사 — 각 단계마다 1~2회, 클라이맥스에 `cardW * 2.0` 크기
- [x] 링 두께 0.06, 퍼지며 fade out (800ms)
- [x] 색상 `(0.3, 0.5, 0.8)`, 원형 edgeFade 적용

#### 1-6. 어둠 소용돌이 (spawnDarkVortex)
- [x] 시전자 주변에서 어둠 입자가 나선형으로 빨려들어감 (3500ms 지속)
- [x] 40~70ms 간격으로 입자 지속 생성
- [x] 각 입자: 랜덤 각도에서 생성 → 나선 경로로 600~1000ms에 걸쳐 중심으로 수렴 → dispose

#### 1-7. 어둠 빔 (spawnDarkBeams)
- [x] 시전자 위로 솟아오르는 보라색 에너지 기둥 5개 (200ms 간격)
- [x] 각 빔: `cardW * 0.04` 폭, `h * 1.5` 높이
- [x] Additive Blending + 위아래 yFade로 사각형 경계 제거
- [x] 800ms에 걸쳐 fade out
- [x] 빌드업 동안 총 3세트(15개) 발사

#### 1-8. 바닥 균열 (spawnGroundCracks)
- [x] 시전자 아래에서 6방향으로 퍼지는 보라색 균열
- [x] 각 균열: `cardW * (1.5~2.5)` 길이, 시간에 따라 바깥으로 확장
- [x] 양 끝 xFade로 사각형 경계 제거
- [x] 1200ms에 걸쳐 fade out
- [x] 총 2세트 발사 — 두 번째는 1.3배 크기

#### 1-9. 점층적 흔들림
- [x] 6단계 escalation: `cardW * (0.05 → 0.1 → 0.2 → 0.4 → 0.7 → 1.2~1.5)`
- [x] `shakeScene`이 항상 원점(0,0) 기반으로 진동 — 겹쳐도 위치 어긋남 없음
- [x] 마지막 단계에서 자연스럽게 원점 복귀

#### 1-10. 클라이맥스
- [x] 이중 플래시 (250ms + 200ms)
- [x] 최대 강도 흔들림 (`cardW * 1.2` → `cardW * 1.5`)
- [x] 최대 냉기 파동 (`cardW * 2.0`)
- [x] 마법진 + 어둠 오라 + 가장자리 어둠 동시 fade out (400/500/600ms)

### 2. 디멘터 비행

#### 2-1. 화면 어두워짐 (progressiveDarken)
- [x] 600ms에 걸쳐 화면 전체가 alpha 0.75까지 어두워짐
- [x] 디멘터가 등장하기 직전에 완료 — 끊김 없는 전환
- [x] AoE 종료 시 600ms에 걸쳐 fade out

#### 2-2. 디멘터 쉐이더 (DEMENTOR_SHADER)
- [x] **단일 유기체 구조** — 후드/망토/연기가 별개 파츠가 아닌 하나의 연속 밀도장(density field)
- [x] **노이즈 시스템**: hash → noise → 5옥타브 FBM(회전 행렬 적용) → warped FBM(자기 참조)
- [x] **바디**: 타원형 밀도장, warped FBM으로 유기적 가장자리 왜곡, xn=0.35~0.50에서 끝남 (올챙이 아님)
- [x] **머리(후드)**: 비대칭 거리 함수 — 앞쪽(얼굴)은 `hx * 1.8`로 좁고, 뒤쪽(뒤통수)은 `hx * 0.7`로 넓게 감싸는 후드 형태. 뒤쪽으로 갈수록 세로 높이 확장
- [x] **내부 난류**: warped FBM + 고주파 FBM이 몸체 내부에 소용돌이치는 어둠 질감 생성
- [x] **연기 구름(trailing smoke)**: warped FBM 3겹 puff (`cloud1/2/3`) — 넓고 뭉게뭉게한 구름, 해파리 촉수가 아닌 볼륨감 있는 연기
- [x] **위습**: FBM 기반 옅은 연기가 흩어지며 사라짐
- [x] **유령 발광**: 연기/위습이 창백한 청백색(`0.48, 0.60, 0.72`) — 얇은 가장자리가 자체 발광, 이중 맥동(`sin 3.5` + `sin 11.0`) + 끝 부분 추가 발광(`wispTipGlow`)
- [x] **눈**: 정면 응시 `:)` 배치 — 세로 나란히 `eyeTop(-0.05, 0.18)`, `eyeBot(-0.05, -0.12)` in fUV 공간. 외부 글로우(dim) + 내부 코어(bright) + 불규칙 깜빡임(3중 sin) + 미세 떨림(jitter)
- [x] **입**: 눈 뒤쪽 `sq=(0.24, 0.50)`. `u_approach`에 따라 크기 확장. 깊고 고요한 파란 심연 — 회전/소용돌이 없음, 느린 호흡 맥동만
- [x] **냉기 오라**: 디멘터 주변 파란 안개 (inner 0.50 + outer 0.40)
- [x] **림 라이트**: 바디 가장자리에 차가운 파란 빛 `(0.15, 0.22, 0.45)`
- [x] **aspect 보정**: 메쉬 비율 0.6에 대한 sq 좌표 변환으로 원형이 실제로 둥글게 렌더링
- [x] **edgeFade 마스크**: UV 경계 6~8%에서 알파 0으로 페이드 — 사각형 보이지 않음 (상단은 3%로 최소화)

#### 2-3. 비행 경로
- [x] **리사주(Lissajous) 곡선**: X축 `sin(phaseX)` + Y축 `sin(phaseY)` — 다른 주기(`dur*2` vs `dur*1.3`)로 멈춤 없는 8자형 연속 비행
- [x] 3마리 각각 다른 출발점/범위/속도: dur `4400/4800/4200ms`
- [x] 200ms 스태거 진입 — 첫 번째는 즉시(setTimeout 없이), 나머지 200/400ms
- [x] 비행 범위: 화면 60~70% 이내 — 화면 밖으로 나가지 않아 빈 화면 없음
- [x] 비행 방향에 따라 `rotation.z` + `scale.y` 플립으로 머리가 항상 진행 방향

#### 2-4. 타이밍
- [x] 디멘터 비행 총 5500ms
- [x] 3마리 전부 퇴장 1400ms (`dementorsFlyAway`)
- [x] 퇴장 후 600ms 긴장 공백

### 3. 솔 키스 (Soul Kiss) — 최종 연출

#### 3-1. 새 디멘터 등장 (spawnSoulKissDementor)
- [x] 화면 밖 랜덤 좌/우에서 새 디멘터 메쉬 생성 — sweep 루프와 충돌 없음
- [x] 초기 `rotation.z = 0` — 처음부터 정면, 회전 없이 등장
- [x] `scale.x = -1` 고정 (sxSign), `scale.y = 1` 고정 (sySign) — 플립 없음

#### 3-2. 돌진 (Phase A, 900ms)
- [x] 화면 밖에서 화면 중앙으로 `t³` 이징 돌진 — 처음 거의 안 움직이다가 마지막에 폭발적 등장
- [x] 입이 화면 정중앙에 오도록 `centerMouthPos()` 함수로 메쉬 위치 보정
- [x] `centerMouthPos`는 메쉬 geometry 파라미터 + 입의 UV 좌표(`sq=0.24,0.50` → `vUv.x=0.76, yn=0.50`)로 정확한 오프셋 계산

#### 3-3. 충격 + 공포 (Phase B, 600ms)
- [x] 도착 즉시: 화면 플래시(250ms) + 강한 흔들림(`cardW * 1.0`) + `u_intensity = 1.0` (눈 최대 발광)
- [x] 서리 오버레이 등장 (`createFrostOverlay`) — FBM 얼음 결정 + 분기 얼음 정맥, 화면 가장자리에서 안쪽 침식
- [x] 600ms 동안 얼굴 고정: 눈 밝기 `1.0 → 0.5`, 입 `u_approach` 0 → 0.5로 서서히 벌어짐
- [x] 서리 강도 0 → 0.5

#### 3-4. 영혼 흡수 (Phase C, 2500ms)
- [x] 디멘터 확대 `6x → 36x` — 입이 화면 전체를 채움
- [x] 입이 항상 화면 정중앙 고정 (`centerMouthPos` 매 프레임 계산)
- [x] `u_approach` 0.5 → 1.0 — 입의 파란 심연이 화면을 지배
- [x] **영혼 스트림 오버레이** (`createSoulStreamOverlay`): warped FBM 기반 파란-흰 에너지가 화면 가장자리에서 중앙으로 흘러들어감
  - 3겹 에너지 레이어 (서로 다른 스케일/속도의 warped FBM)
  - 코어 스트림 — 중앙 근처 밀집된 밝은 흐름
  - 수렴 글로우 — 입 위치 밝은 광점
  - 필라멘트 — FBM 기반 가는 밝은 실
  - 색상 그라데이션: 가장자리 `(0.3, 0.5, 0.95)` → 중심 `(0.85, 0.92, 1.0)`
  - Additive Blending
- [x] 씬 미세 진동 — `eased²` 강도로 점차 강해짐
- [x] 서리 페이드아웃 (800ms, 병렬)

#### 3-5. 암전 + 복귀 (Phase D~F)
- [x] 파란빛 → 검은 암전: 800ms에 걸쳐 검은 오버레이 alpha 0→0.95
- [x] 디멘터 메쉬 dispose (이미 화면 가득 채워 안 보임)
- [x] 영혼 스트림 오버레이 dispose
- [x] 암전 유지 500ms
- [x] 암전 페이드아웃 600ms (alpha 0.95→0)
- [x] 200ms 여유 후 종료
