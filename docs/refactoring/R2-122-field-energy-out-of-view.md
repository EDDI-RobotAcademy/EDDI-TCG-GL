# Issue

1. 창 크기를 바꾸면 종족 그림이 첫 종족으로 되돌아갔다
    - 증상
        - 종족을 트런트로 바꾼 뒤 창 크기를 바꾸면 그림이 휴먼으로 돌아간다. 붙는 종족은 트런트 그대로다
    - 원인
        - 크기 조절이 **처음 만들 때의 종족을 적어 둔 것** 을 계속 들고 있었다
        - 그림을 바꿀 때는 새로 만든 것을 쓰고, 크기를 다시 잴 때는 처음 것을 썼다. 둘이 갈라져 있었다
        - 규칙 28 과 같은 꼴이다 — 들고 있는 값이 시작할 때의 값이다
    - 처리
        - 지금 고른 종족을 적어 둔 것 하나만 두고, 그림을 바꿀 때 그것을 갈아 끼운다. 크기 조절도 그것을 본다
        - **그림이 바뀌는 것은 크기 조절도 바뀐 쪽을 봐야 한다. 처음 것을 들고 있으면 창 크기가 되돌리개가 된다**

2. 아무도 안 부르는 것 둘이 남아 있었다
    - 증상
        - 카드 종족을 읽어 주는 것과 상대 판을 흔들어 주는 것 둘이 만들어만 두고 안 쓰였다
    - 원인
        - 카드 종족은 전투에 넘겨 주는 창구가 읽게 바뀐 뒤 (R2-112) 남았고, 상대 판 흔들기는 창구로 옮겨진 뒤 남았다
        - **타입 검사는 만들어 두고 안 쓰는 것을 안 잡는다**
    - 처리
        - 옮기기 전에 이름으로 세어 지웠다
