# Issue

1. 카드 칸이 카드 비율이 아니었다 — 사용자가 찾았다
    - 증상
        - 창 높이를 줄이면 카드가 납작해졌다
    - 원인
        - 칸이 남은 자리를 나눠 갖고 있었다 (`height: 64vh` 를 두 줄로)
        - 1366x768 에서 세로/가로가 1.16, 1280x600 에서 0.91 이 됐다. **1 보다 작으면 가로로 누운 것이다**
    - 처리
        - 카드 폭 = min(가로로 넣을 수 있는 폭, 세로에 들어가는 폭). 칸 높이는 거기에 비율을 곱해 낸다
        - **가로와 세로를 둘 다 봐야 한다.** 하나만 보면 다른 쪽으로 넘친다 — 2560x1080 에서 그랬다
        - R2-135 에서 같은 것을 고쳐 놓고 격자에서 또 했다

2. 앞면이 카드가 아니라 액자였다 — 사용자가 찾았다
    - 증상
        - 뒤집으면 카드가 쪼그라들었다
    - 원인
        - 카드 그림은 **이미 완성된 카드 한 장**이다. 테두리도 이름도 설명도 찍혀 있다
        - 그것을 또 테와 여백 안에 줄여 넣고 있었다. 뒷면은 칸을 꽉 채우는데 앞면만 작았다
    - 처리
        - 그림이 면을 채운다. 얹을 것은 자리를 안 차지하는 겹으로 둔다
        - **그림 파일의 크기가 카드 크기가 아니다** — 952x1540 판 안에 927x1501 카드가 들어 있고 둘레 1.3% 가 투명하다
        - 뒷면을 그 규격에 맞춰 다시 만들었다. 판도 카드도 여백도 같으니 같은 규칙 한 줄로 겹친다

3. 어두운 판에 맞춰 잡은 색을 밝은 종이에 그대로 썼다
    - 증상
        - 등급표의 희귀(금색)가 양피지에 묻혔다
    - 원인
        - 색을 고를 때의 바탕이 남색 판이었다. 바탕이 바뀌었는데 색을 다시 안 봤다
    - 처리
        - 글자는 먹빛, 색은 동그라미가 맡는다. 동그라미에 어두운 테를 둘러 옅은 색도 읽히게 한다
        - **색은 바탕과 한 쌍이다.** 바탕을 바꾸면 색을 다시 봐야 한다

4. 자리를 픽셀로 적으면 그림을 안 따라간다
    - 증상
        - 양피지에 그려진 Again / Lobby 딱지를 눌러야 하는데, 창 크기가 바뀌면 어긋난다
    - 원인
        - 그림이 창 크기에 따라 커졌다 작아졌다 한다
    - 처리
        - 딱지 자리도 카드 자리도 등급표 자리도 전부 **그림 크기에 대한 비율**로 적는다
        - 그림을 늘리거나 잘라 채우지 않는다. 그러면 그림 속 딱지가 옮겨 앉는다

5. 빛줄기를 기울였더니 카드 밖으로 샜다
    - 증상
        - 대각선으로 바꾸자 빛이 카드 테두리를 넘어갔다
    - 원인
        - 자르는 틀째로 움직이고 있었다. 틀이 움직이면 자르는 자리도 같이 움직인다
    - 처리
        - **틀은 가만히 두고 안에 든 것만 움직인다**
