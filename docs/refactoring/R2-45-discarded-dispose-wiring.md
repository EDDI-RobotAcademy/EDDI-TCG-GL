# Success criteria

1. 왜 하려 했는지
    - R2-25 에서 화면 메시를 버리는 약속을 만들고 카드 메시를 담는 다섯 곳에 붙였다
    - 그때는 만들어만 두고 아무도 부르지 않았다. 지금 안 버리던 것을 버리기 시작하면 아직 쓰고 있는 것을 버릴 수 있어서였다
    - 이 작업은 그 약속을 실제로 부르는 일이었다

2. 왜 접었는지
    - 부를 자리가 없고, 부를 이유도 없다
    - R2-25 에서 [카드가 화면에서 빠질 때 버린다] 고 적었는데, 그 전제가 틀렸다

3. 무엇이 틀렸는지 — 카드는 지워지지 않고 감춰진다

```
유닛이 죽을 때
    무덤에 카드 번호를 넣는다
    살아 있는 목록에서 뺀다
    메시를 감춘다 (visible = false)
    나머지를 다시 줄 세운다
```

    - 지우는 것이 아니라 감추는 것이다. 그리고 그것이 맞다
    - 부활하면 살아 있는 목록에 다시 넣고 줄 세우기만 부르면 된다. 좌표는 그 함수가 잡는다
    - 로스트 존에서 가져올 때도, 손패로 돌려놓을 때도 같다
    - 손패 카드와 필드 카드가 같은 메시다. 손패에서 쓰던 덩어리를 그대로 필드로 옮긴다

4. 새고 있지 않다
    - 감춰둔 메시는 카드마다 하나다. 필드에 나올 수 있는 카드는 덱에 든 만큼이 최대다
    - 한 판에 몇 번 죽고 살아나든 메시 수가 늘지 않는다
    - 버려야 할 이유가 없다

5. 이미 버리고 있는 자리도 있다
    - 손패에서 아이템 카드를 써서 소모될 때는 화면에서 빼고 자원을 놓아준다
    - 그 카드는 다시 안 돌아온다. 그래서 버리는 것이 맞다

```
소모되는 카드    화면에서 빼고 놓아준다     이미 그렇게 되어 있다
죽는 유닛        감춘다                    부활에 대비한 것이다
```

# Issue

1. 자원이 샌다고 보고 티켓을 세웠다
    - 증상
        - R2-25 에서 [카드가 무덤에 갈 때마다 그림 한 장이 그래픽 카드에 남는다] 고 적었다
        - 실제로는 감춰서 들고 있는 것이고, 부활하면 다시 쓴다
    - 원인
        - 저장소가 지도에서 빼기만 하는 것을 보고 [화면에서도 빠지는데 자원만 남는다] 고 읽었다
        - 화면에서 어떻게 빠지는지는 확인하지 않았다
    - 처리
        - 확인하고 접었다
        - **무엇을 버릴지 정하기 전에 지금 어떻게 사라지는지 본다.** 사라지는 방법이 여럿이다

2. 감추는 것과 지우는 것을 한 가지로 봤다
    - 증상
        - visible = false 를 보고 [안 치운 것] 으로 읽었다
    - 원인
        - 손패 페이지 넘김에도 같은 코드가 쓰인다. 그것과 죽음을 구분하지 않았다
    - 처리
        - 둘 다 감추는 것이 맞다. 페이지를 넘기면 돌아오고, 부활하면 돌아온다
        - **감춘 것은 돌아올 것이다.** 돌아오지 않는 것만 버린다
