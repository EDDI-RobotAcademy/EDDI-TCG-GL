# [ETWGL-R2-66] 카드 능력을 쓰는 일을 전투 상태가 처리한다

선행: R2-65 │ 후행: R2-67 │ 산출물: 카드 다섯을 전투가 처리한다 │ Type: Rule │ Domain: Battle Ability

# Success criteria

1. 왜 하는지와 어디까지 할지를 정한다
    - 문제
        - 카드 하나를 쓸 때 화면이 넷에서 열 줄을 순서대로 부른다
        - 피해를 주고, 죽었는지 보고, 무덤에 넣고, 필드에서 빼고, 카드를 무덤에 넣는 것을 화면이 다 조립한다
        - 하나만 빠져도 어긋나는데 막을 방법이 없다
    - 목적
        - 카드를 쓰는 일 하나를 전투가 받아 끝까지 처리하고, 무슨 일이 있었는지 돌려주게 한다
    - 기대 결과
        - 화면은 하나만 보내고 돌려받은 것으로 연출을 튼다
    - 건드리지 않는 것
        - 공격과 스킬 - R2-67
        - 값으로 안 되는 카드 넷 - R2-58 에서 가려낸 것이다. 한 번에 안 끝난다

2. 어떤 카드부터 옮길지 정한다
    - R2-58 판정표에서 값으로 다 적히는 여덟 중 다섯을 옮긴다
    - 고르는 방식이 다른 것을 골고루 넣어 길이 맞는지 본다
    - 유닛 하나, 내 유닛 하나, 상대 필드 전체, 내 필드 전체

3. 카드가 무엇을 겨누는지에 따라 보내는 것을 나눈다
    - 유닛 하나에게 쓰는 것과 필드 전체에 쓰는 것은 함께 오는 것이 다르다
    - 유닛 하나에는 어느 유닛인지, 필드 전체에는 어느 쪽 필드인지가 온다

4. 연출 시점을 어떻게 맞출지 정한다
    - 값은 보내는 순간 다 바뀐다. R2-62 에서 정한 대로다
    - 화면은 돌려받은 것을 들고 있다가 연출의 알맞은 순간에 쓴다
    - 폭발이 터질 때 숫자가 바뀌는 것, 알갱이가 닿을 때 하나씩 오르는 것이 그렇다

5. 게임 동작이 달라지지 않았는지 확인한다
    - 카드 열두 장 전부
    - 뽑은 카드를 필드에 낼 수 있는지

# Issue

1. 카드 번호를 화면과 전투가 각자 매기고 있었다
    - 증상
        - 뽑거나 가져온 유닛 카드를 필드에 낼 수 없었다. 사용자가 찾아 줬다
        - 처음에는 되는데 카드를 몇 장 쓰고 나면 안 된다
    - 원인
        - 화면은 화면 카드 목록의 길이를 번호로 썼다. 목록이 안 줄어서 계속 오른다
        - 전투는 지금 있는 것 중 가장 큰 번호 다음을 썼다. 카드를 쓰면 그 번호가 되돌아온다
        - 각자 0 부터 세니 처음에는 맞다가 갈라진다
    - 처리
        - 전투가 번호를 매기게 했다. 한 번 준 번호는 다시 안 준다
        - 카드가 손패에 들어오는 곳 셋이 모두 그 번호를 쓰게 했다
        - **R2-55 에서 적은 [각자 0 부터 세면 처음에는 늘 맞는다] 가 또 나왔다**

2. 레오닉의 부름이 전투의 손패에 안 넣고 있었다
    - 증상
        - 가져온 카드가 화면에만 있고 전투의 손패에는 없었다
    - 원인
        - 그 카드는 아직 전투가 처리하는 카드가 아니다. 화면이 덱에서 직접 빼서 화면에만 붙였다
    - 처리
        - 전투에도 넣게 했다. 능력 자체를 옮기는 것은 나중이지만 손패는 지금 맞춰야 한다
        - **일부만 옮기면 옮긴 것과 안 옮긴 것의 경계에서 어긋난다.** 경계를 먼저 찾는다

3. 카드를 치우는 일이 두 가지였다
    - 증상
        - 화면에서 치우는 것과 무덤에 넣는 것이 한 함수에 있었다
        - 전투가 무덤에 넣기 시작하니 두 번 들어간다
    - 원인
        - 값과 화면을 함께 다루던 함수다
    - 처리
        - 둘로 갈랐다. 전투가 처리하는 카드는 화면에서 치우기만 부른다
        - **옮기는 도중에는 옛 길과 새 길이 같이 산다.** 겹치는 부분을 갈라 둬야 한다
