# Issue

1. 사용처를 셀 때 쓰는 쪽 폴더를 제외했다
    - 증상
        - 세 애니메이션이 아무 데서도 쓰이지 않는다고 판단했는데, 각자의 핸들러가 쓰고 있었다
    - 원인
        - 사용처를 셀 때 first_skill, second_skill, general_attack 폴더를 제외하고 셌다
        - 그 폴더 밖에서 쓰는 곳을 찾으려던 것인데, 정작 쓰는 것이 같은 폴더 안의 핸들러였다
        - 제외 조건을 왜 넣었는지 다시 보지 않고 결과만 읽었다
    - 처리
        - 자기 파일만 제외하고 다시 세어 세 핸들러가 각각 쓰는 것을 확인했다
        - 앞으로 사용처를 셀 때는 자기 파일만 제외한다. 폴더를 제외하면 같은 폴더 안의 사용을 놓친다

2. 죽은 코드라는 판단이 작업을 하나 만들어냈다
    - 증상
        - 쓰지 않는 코드로 보여 별도 작업으로 뺐는데, 확인해보니 할 일이 없었다
    - 원인
        - 세는 방법이 틀린 것을 확인하지 않고 작업을 나눴다
    - 처리
        - 이 작업을 폐기하고 세 파일을 R2-12 범위에 넣었다
        - 연출이므로 핸들러와 함께 두지 않고 연출 쪽으로 간다
