# Issue

1. 카드 하나가 함수 하나가 아니었다
    - 증상
        - 카드 번호로 함수 하나를 꺼내는 표를 만들려니 네더 블레이드가 안 담겼다
    - 원인
        - 그 카드는 [나올 때] 와 [고르기가 끝났을 때] 두 자리에 각각 들어간다
        - 시체 폭발도 [쓸 때] 와 [고르기가 끝났을 때] 둘이다
    - 처리
        - 카드 하나를 함수 하나가 아니라 **칸 여럿을 가진 기록 하나** 로 만들었다
        - 안 채운 칸은 그 방식으로 못 쓴다는 뜻이다. 전에 [처리하지 않는 카드] 로 돌려주던 자리가 이것이다
        - **표를 만들 때 열쇠가 카드 번호 하나인지, 카드와 상황 둘인지 먼저 본다**

2. 카드에게 무엇을 넘기느냐가 진짜 결정이었다
    - 증상
        - 카드별 함수들이 처리기의 것을 여섯 가지, 전투의 것을 스무 가지쯤 부르고 있었다
    - 원인
        - 처리기를 통째로 넘기면 카드가 아무거나 부를 수 있다. 갈림길을 파일로 흩어 놓은 것이 될 뿐이다
    - 처리
        - 카드가 쓸 수 있는 것을 여섯 가지로 적어 창구를 만들었다. 처리기 자신은 안 넘긴다
        - 전투 자체는 넘긴다. 카드 규칙도 규칙 쪽이라 그 경계는 문제가 아니다
        - **이 목록이 곧 [카드가 할 수 있는 일] 이다. 새 카드가 여기 없는 것을 필요로 하면 그때 늘린다 (규칙 24)**

3. 파일이 서로 물고 돌 뻔했다
    - 증상
        - 카드 파일이 카드에 적힌 것을 읽어야 하는데, 그것이 처리기 파일 안에 있었다
        - 처리기는 카드 파일을 부른다. 그대로 두면 둘이 서로를 가리킨다
    - 원인
        - 카드에 적힌 것을 읽는 자리가 처음부터 자리를 잘못 잡고 있었다
    - 처리
        - 능력 폴더로 옮겼다. 카드에 적힌 것이니 거기가 맞다
        - **파일을 가르기 전에 서로 가리키는 방향을 먼저 본다. 검사가 오류로 막는다**

4. 옮기면서 갈림길 하나가 저절로 없어졌다
    - 증상
        - 죽음의 에너지와 암흑 에너지가 한 함수를 나눠 쓰고 있었고, 그 안에 어느 카드인지 보는 줄이 있었다
    - 원인
        - 둘이 거의 같아서 한 함수로 묶여 있었다. 다른 한 가지만 조건으로 갈라져 있었다
    - 처리
        - 파일이 갈리면서 조건이 사라졌다. 암흑 에너지 파일은 늘 표시를 붙이면 된다
        - **비슷해서 묶어 둔 것은 가르면 조건이 없어진다. 조건이 남으면 잘못 가른 것이다**

## 칸은 다섯이 됐다

처음에 넷으로 세었는데 옮기는 중에 하나가 더 나왔다.

| 칸 | 언제 | 채운 카드 |
| --- | --- | --- |
| 유닛에 대고 쓴다 | 손패 카드를 유닛에 떨어뜨렸다 | 일곱 |
| 필드에 쓴다 | 손패 카드를 필드에 떨어뜨렸다 | 넷 |
| 고르기가 끝났다 | 고르라고 기다리던 것을 다 골랐다 | 둘 |
| 이 카드가 나왔다 | 유닛이 필드에 섰다 | 하나 |
| 이걸 고르면 얼마 맞나 | **연출을 시작하기 전에 결과를 알아야 한다** | 둘 |

다섯째는 R2-105 에서 만든 [죽는 일격인가] 안에 카드 번호 갈림길이 남아 있어서 생겼다.
**이 카드만 쓰는 칸이 아니라 고르기를 가진 카드 둘이 같이 쓰는 칸** 이라 칸으로 만들었다.
한 카드만 쓰는 칸을 만들기 시작하면 갈림길을 파일로 흩어 놓은 것이 된다.

## 카드가 할 수 있는 일 여섯

| 무엇 | 쓰는 카드 |
| --- | --- |
| 쓴 카드를 무덤으로 보낸다 | 열 |
| 상대 유닛을 깎는다 | 넷 |
| 상대 유닛을 쓰러뜨린다 | 둘 |
| 상대 본체를 깎는다 | 둘 |
| 고르라고 기다리기 시작한다 | 둘 |
| 방금 이 유닛이 쓰러졌는지 묻는다 | 둘 |

여기에 전투 자체를 더해 넘긴다. **처리기 자신은 안 넘긴다.**

새 카드가 이 목록에 없는 것을 필요로 하면 그때 늘린다. 규칙 24 에 적힌 대로,
없던 규칙이 실제로 나왔으면 공통이 자라는 것이 정상이다. **안 늘리고 카드만 느는 것이
통과다.**

## 절반만 됐다

제목이 [기존 카드의 코드를 고치지 않도록] 인데, **규칙 쪽만 그렇다.**

| | 카드를 새로 만들 때 |
| --- | --- |
| 규칙 | 파일 하나를 놓고 명부에 한 줄. 다른 카드는 안 건드린다 |
| 연출 | **여전히 전투 화면을 고쳐야 한다** |

화면 쪽을 지금 안 한 이유는 뺄 자리가 없어서다. 연출 하나가 바깥에서 끌어다 쓰는 것이
연출 객체와 다시 세우기와 읽기 창구인데, 화면 전체가 4225줄짜리 한 공간이라 **무엇만
있으면 되는지가 정해질 수가 없다.** 지금 빼면 그 공간을 통째로 넘기는 큰 꾸러미를 만들게
되고, R2-115 에서 다시 뜯는다.

R2-116 을 세웠다. R2-115 가 화면을 가르고 나서 한다.

| 구분 | 내용 |
| --- | --- |
| **잘 맞은 것** | 표의 열쇠를 카드 번호 하나가 아니라 카드와 상황 둘로 잡았다. 하나로 잡았으면 카드 둘이 안 담겼다. |
| **잘 맞은 것** | 처리기를 안 넘기고 할 수 있는 일을 여섯으로 적었다. 넘겼으면 갈림길을 파일로 흩어 놓은 것이 됐다. |
| **잘 맞은 것** | 규칙 쪽을 먼저 하고 화면 쪽은 결과를 보고 판단했다. 한꺼번에 했으면 뭐가 깨졌는지 못 가렸다. |
| **미흡한 것** | 제목의 절반만 됐다. 카드를 새로 만들 때 연출은 여전히 화면을 고쳐야 한다. |
