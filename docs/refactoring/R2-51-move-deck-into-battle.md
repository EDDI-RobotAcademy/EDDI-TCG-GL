# [ETWGL-R2-51] 덱을 전투 상태 안으로 옮긴다

선행: R2-50 │ 후행: R2-52 │ 산출물: Battle 이 내 덱과 상대 덱을 들고 있다 │ Type: Rule │ Domain: Battle Deck

# Success criteria

1. 왜 하는지와 어디까지 할지를 정한다
    - 문제
        - 내 덱과 상대 덱이 전투 밖의 저장소에 따로 있다
        - 덱은 순서가 있다. 순서가 어긋나면 다음에 뽑히는 카드가 달라진다
        - 그런데 섞는 방식이 무작위라 같은 판을 다시 만들 수 없다
    - 목적
        - 덱을 전투 한 판 안으로 옮기고, 섞은 결과를 다시 만들 수 있게 한다
    - 기대 결과
        - 전투를 통째로 적으면 덱의 순서도 함께 적힌다
        - 씨앗을 적어 두면 섞인 순서를 그대로 다시 만든다
    - 건드리지 않는 것
        - 덱을 짜는 화면 - 전투가 아니다. 전투 중의 덱과 제어 방식이 정반대다
        - 무덤과 로스트 존 - R2-52, R2-53
        - 상대 덱을 뒤지는 길 - 그런 카드가 아직 없다. 나오면 그때 낸다

2. 무작위를 어떻게 다룰지 정한다
    - 도메인 안에서는 무작위를 쓸 수 없다. 같은 입력에 다른 결과가 나오면 되돌릴 수 없다
    - 섞을 때 쓸 씨앗을 밖에서 받는다. 도메인은 그 씨앗만 쓴다
    - 씨앗 하나로 같은 순서를 다시 만들어 내는 방식을 도메인 안에 둔다
    - 플레이어가 보기에는 그대로 무작위다. 씨앗을 매번 새로 만들기 때문이다

3. 내 덱과 상대 덱을 어떻게 둘지 정한다
    - 섞는 방식과 뽑는 방식은 양쪽이 같다. 안쪽은 하나로 둔다
    - 밖으로 내는 길은 지금 쓰는 만큼만 낸다
    - 내 덱은 일곱, 상대 덱은 넷이다. 상대 덱을 뒤지는 카드가 아직 없다

4. 쓰던 곳을 바꾸고 옛것을 지운다
    - 덱을 쓰는 곳은 확인용 화면 하나다
    - 덱을 채우는 것이 전투가 시작되기 전에 있어서 시작하는 자리를 앞으로 옮긴다
    - 옛 저장소와 쓰는 곳이 없던 타입을 지운다

5. 게임 동작이 달라지지 않았는지 확인한다
    - 카드 뽑기, 레오닉의 부름, 망자의 늪
    - 레오닉을 여러 번 써서 매번 다른 순서가 나오는지

# Issue

1. 섞는 방식이 도메인 규칙에 걸렸다
    - 증상
        - 덱이 스스로 무작위를 불러 섞고 있었다. 도메인 안에서는 금지된 것이다
    - 원인
        - 같은 입력에 다른 결과가 나오면 재접속했을 때 서버와 화면이 다른 순서를 갖는다
    - 처리
        - 씨앗을 밖에서 받고 도메인은 그 씨앗만 쓰게 했다. 규칙이 정해 둔 방법 그대로다
        - **무작위를 없앤 것이 아니라 적어 둘 수 있게 만든 것이다.** 플레이어가 보기에는 그대로다

2. 값을 채우는 것이 전투가 시작되기 전에 있었다
    - 증상
        - 확인용 화면이 덱을 먼저 채우고 한참 뒤에 전투를 시작하고 있었다
    - 원인
        - 각 저장소가 혼자 있는 것이라 순서가 상관없었다. 아무 때나 채워도 됐다
    - 처리
        - 전투를 시작하는 자리를 덱을 채우기 앞으로 옮겼다
        - **한 곳에 모으면 순서가 생긴다.** 담을 그릇이 먼저 있어야 담는다

3. 양쪽이 같아 보이지만 쓰는 길이 다르다
    - 증상
        - 내 덱에는 섞기와 뒤지기가 있고 상대 덱에는 없다
    - 원인
        - 레오닉의 부름과 넘쳐 흐르는 사기가 내 덱을 뒤진다. 상대 덱을 뒤지는 카드는 아직 없다
    - 처리
        - 안쪽 규칙은 하나로 두고 밖으로 내는 길만 다르게 냈다
        - **같은 것을 두 번 쓰지 않으면서 지금 없는 길을 미리 열지 않는다.** 길을 열면 쓰는 곳이 생기고 되돌리기 어렵다
