# Issue

1. 시킨 일을 좁게 읽어서, 만들어 놓고도 아무 일도 안 일어나 보였다 — 사용자가 찾았다
    - 증상
        - 「테스트용 전장 들어갔는데 아무 일도 없는데?」
    - 원인
        - **손패 내용만 바꿨다.** 판은 그대로 차려져 있었다 — 필드 에너지 19/15, 무덤 열두 장,
          상대 유닛 일곱. 그 위에서 손패 열두 장이 다섯 장으로 준 것은 눈에 안 들어온다
        - 「대전 매칭 시 무작위 5장 지급」 을 [손패 목록을 바꾼다] 로 읽었다. 실제로는
          **[대전이 시작되는 모습을 만든다]** 였다
    - 처리
        - 판을 비우고, 받은 카드를 화면 가운데 크게 보여 준다
        - **[무엇을 바꾸나] 가 아니라 [사용자가 무엇을 보게 되나] 로 범위를 잡는다.**
          값을 바꿔도 화면에 안 드러나면 한 일이 아니다

2. 「아무 일도 없다」 를 [깨졌다] 로 읽고 한참 엉뚱한 데를 팠다
    - 증상
        - 빌드도 검사도 멀쩡한데 화면이 안 된다고 하니, 터지는 곳을 찾느라 여러 번 헛돌았다
    - 원인
        - 「아무 일도 없다」 에 두 뜻이 있다 — **화면이 안 뜬다** 와 **달라진 게 없다**
        - 앞쪽으로 단정하고 카드 자료, 그림 파일, 낡은 묶음을 차례로 뒤졌다. 전부 멀쩡했다
    - 처리
        - 재현이 안 되면 **먼저 무엇이 보이는지를 묻는다.** 추측으로 파기 전에 한 번 묻는
          것이 훨씬 싸다

## 사용자가 보는 순서

```
전투에 들어온다
  ↓  받은 다섯 장이 화면 가운데 크게 뜬다 (한 장씩 110밀리초 차이로)
[시작] 을 누른다
  ↓  겹이 걷힌다
그 카드들이 손패에 있다
```

**손패는 아래에 이미 깔려 있다.** 이 겹은 그 위를 덮고 있을 뿐이라 걷히면 바로 쓸 수 있다.
여기서 카드를 손패로 옮기지 않는다 — 옮기는 것은 판을 차릴 때 끝났다.

## 섞는 자리

```
도메인       무작위를 못 쓴다 (순수해야 한다)
화면         규칙을 돌리면 안 된다
판 차리기 ←  여기가 맡는다.  서버가 붙으면 이 함수를 안 부른다
```

`dealOpeningHand()` 이 내놓는 것은 **값 둘**이다 — 손에 쥘 카드 번호와 남은 덱.
`simulation-writes-values-only` 를 그대로 지킨다.

피셔-예이츠로 섞는다. 두 자리를 아무렇게나 골라 바꾸면 **자리마다 나올 확률이 달라지는데**,
눈으로는 섞인 것처럼 보여서 틀려도 모른다. 5,000번 돌려 장수에 비례하는 것을 확인했다.

## 지우지 않고 남긴 것 둘

| | 되살리는 법 | 무엇을 보려던 것인가 |
| --- | --- | --- |
| 차려 둔 판 | `USE_CHECK_BOARD = true` | 무덤 팝업 페이지 넘기기, 공격할 상대, 에너지 드는 카드 |
| 붙박이 손패 | `FIXED_OPENING_HAND = [...]` | 네더 블레이드 죽음의 낫, 시체 폭발, 망자의 늪 같은 카드 동작 |

**무작위로 받으면 보고 싶은 카드가 손에 안 들어온다.** 특정 카드를 확인할 때 이 둘이 없으면
될 때까지 들락거려야 한다.
