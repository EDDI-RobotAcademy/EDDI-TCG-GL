선행: R2-56 │ 후행: R2-58 │ 산출물: Battle 이 손패를 들고 있다 │ Type: Rule │ Domain: Battle Hand

# Success criteria

1. 왜 하는지와 어디까지 할지를 정한다
    - 문제
        - 손패가 저장소 둘에 흩어져 있다. 한 장씩의 속사정을 담는 것과 시작 목록을 담는 것
        - 시작 목록 쪽은 자리와 신원이 한 값이라 R2-55 에서 고친 것과 같은 문제를 갖고 있다
        - 손패의 시작 카드 넉 장이 저장소 생성자 안에 있다. 값을 담는 곳이 시나리오를 정하고 있었다
        - 몇 장씩 나눠 보여줄지를 저장소가 정하고 있었다. 그것은 화면이 정할 일이다
    - 목적
        - 손패를 전투 한 판 안으로 옮긴다. 일곱 도메인 중 마지막이다
    - 기대 결과
        - 전투를 통째로 적으면 손패도 함께 적힌다
        - 흩어져 있던 일곱이 모두 한 곳에 모인다
    - 건드리지 않는 것
        - 손패를 그리는 것 - 화면이다
        - 화면 좌표 번호 - 도메인 값이 아니다. 필드 카드와 함께 걷어낸다. R2-61
        - 낡은 방식 표시가 붙은 옛 손패 저장소 - R2-66 부터의 다섯 단계에서 본다

    - 안쪽 규칙은 필드와 같지만 따로 만든다. 손패는 상대가 못 본다
    - 상대의 손패를 뒤지거나 버리게 하는 카드가 붙으면 손패만 바뀐다

3. 화면이 정할 일을 전투에서 뺀다
    - 몇 장씩 나눠 보여줄지는 화면이 정한다
    - 전투는 목록만 주고, 자르는 것은 부르는 쪽에서 한다

4. 시나리오 값을 저장소에서 빼낸다

    - 값이 나오는 차례가 열쇠 차례와 다르다. 넣은 차례대로 나온다
    - 카드를 뽑을 때 목록에 따로 넣던 줄을 없앤다. 손패에 넣는 곳이 하나가 된다

5. 게임 동작이 달라지지 않았는지 확인한다

# Issue

1. 이름이 겹치는 것을 만들 뻔했다
    - 증상
        - 손패에 든 카드 한 장을 HandCard 라 지으려 했는데, 그 이름이 이미 있었다
        - 이미 있던 것은 카드 앞면에 적혀 있는 것이었다. 종류, 병종, 종족, 체력, 공격력, 에너지 수
    - 원인
        - 손패 폴더 안에 있어서 손패에 든 카드일 것이라 여겼다
    - 처리
        - 이미 있던 쪽을 CardFace 로 바꿨다. 카드 앞면이라는 뜻이 그대로 드러난다
        - **같은 이름을 쓰기 전에 그 이름이 이미 무엇을 가리키는지 연다.** 폴더 이름으로 짐작하지 않는다

2. 값이 나오는 차례가 열쇠 차례와 달랐다
    - 증상
        - 시작 카드를 담은 지도가 0, 2, 3, 1 순으로 채워져 있었다
        - 열쇠 차례로 읽으면 2, 26, 19, 93 이고 넣은 차례로 읽으면 2, 19, 93, 26 이다
    - 원인
        - 값을 꺼내는 길이 열쇠를 안 보고 넣은 차례를 준다
    - 처리
        - 넣은 차례로 옮겼다. 옮기기 전에 실제로 어떤 차례가 나오는지 확인했다
        - **자리를 열쇠로 쓰는 곳에서 값을 옮길 때는 열쇠가 아니라 나오는 차례를 본다**

3. 손패에 넣는 곳이 둘이었다
    - 증상
        - 카드를 뽑을 때 시작 목록에도 넣고 손패 저장소에도 넣고 있었다
    - 원인
        - 시작 목록이 시작할 때만 쓰이는 것이 아니라 뽑을 때도 쓰였다
    - 처리
        - 시작 목록을 없애면서 넣는 곳이 하나가 됐다
        - **시작값을 담는 곳에 나중에도 넣기 시작하면 그것은 더 이상 시작값이 아니다**

4. 페이지 나누기가 값을 담는 곳에 있었다
    - 증상
        - 손패 저장소가 [몇 쪽의 몇 장] 을 잘라서 줬다
    - 원인
        - 화면이 그렇게 보여주니 담는 곳도 그렇게 주는 것이 편했다
    - 처리
        - 전투는 목록만 주고 자르는 것은 부르는 쪽에서 하게 했다
        - **화면이 어떻게 보여주는지가 값을 담는 곳의 모양을 정하면 안 된다**
