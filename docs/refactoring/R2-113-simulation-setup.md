# Issue

1. 열 군데가 다 같은 것이 아니었다
    - 증상
        - 통째로 옮기려니 둘이 안 옮겨졌다. 손패와 상대 필드다
    - 원인
        - 이 둘은 화면이 그린 카드의 번호를 신원으로 쓴다. 그리기 전에는 그 번호가 없다
        - 나머지 여덟(필드 에너지 둘, 덱 둘, 무덤 둘, 로스트 존 둘)은 아무것에도 안 기댄다
    - 처리
        - 차림표가 그 둘을 밖에서 받게 했다. 나머지 여덟은 차림표 안에 값으로 적었다
        - 차림 시점을 손패와 상대 필드를 그린 뒤로 옮겼다
        - **[여기서 안 옮겨지는 것] 이 곧 [바깥에 기대는 것] 이다. 무엇에 기대는지가 거기서 드러난다**

2. 왜 그 값인지가 적혀 있지 않았다
    - 증상
        - 무덤에 열두 장, 로스트 존에 열두 장, 상대 필드에 네더 블레이드 둘
    - 원인
        - 옮기기 전에는 그리는 코드 옆에 있어서 짐작이 됐다. 떼어 놓으면 왜 그 수인지 모른다
    - 처리
        - 차림표에 이유를 적었다. 열두 장은 팝업이 한 쪽에 열 장이라 두 쪽이 되게 한 것이고,
          네더 블레이드 둘은 같은 대상을 두 번 고르는 카드와 패시브 겹침을 보려는 것이다
        - **떼어 놓는 값에는 왜 그 값인지를 함께 옮긴다. 안 옮기면 다음 사람이 함부로 고친다**

3. 예외를 지웠더니 검사가 그대로 통과했다
    - 증상
        - 경계 검사에 예외로 남아 있던 파일 하나를 지웠는데 아무것도 안 걸렸다
    - 원인
        - 화면이 규칙 물건을 만들던 자리가 이 열 군데뿐이었다
    - 처리
        - 예외 칸을 없애고 [다시 채우지 않는다] 고 적었다
        - 차림표는 그 검사 밖에 있다. 규칙 물건을 직접 만드는 것이 허용되는 유일한 자리라
          폴더를 따로 두어 그리는 코드로 새지 않게 했다
        - **허용되는 예외는 주석이 아니라 폴더로 가둔다**

## 네트워크가 붙을 때

```
지금    전투 화면  →  차림표를 한 번 부른다  →  판이 차려진다
나중    전투 화면  →  서버가 준 것을 받는다
```

바뀌는 곳은 **부르는 한 줄** 이다. 전에는 그리는 코드 사이 열 군데를 찾아 지워야 했다.

| 구분 | 내용 |
| --- | --- |
| **잘 맞은 것** | 안 옮겨지는 둘이 무엇에 기대는지를 드러냈다. 억지로 옮겼으면 차림표가 화면을 알게 됐다. |
| **잘 맞은 것** | 왜 그 값인지를 값과 함께 옮겼다. 열두 장이 왜 열두 장인지가 안 적혀 있었다. |
| **잘 맞은 것** | 허용되는 예외를 주석이 아니라 폴더로 가뒀다. 검사가 폴더로 가른다. |
| **미흡한 것** | 차림표가 손패와 상대 필드를 밖에서 받는다. 신원 번호를 화면이 정하기 때문이고, 서버가 번호를 주게 되면 없어진다. |
