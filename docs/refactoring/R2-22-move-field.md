# Issue

1. 이름이 비슷해 하나로 볼 뻔했다
    - 증상
        - your_field, your_field_area, your_field_map 이 이름만으로는 다 [내 필드] 로 읽힌다
    - 원인
        - 폴더 이름이 무엇을 담는지 말해주지 않는다. 셋 다 field 로 끝난다
    - 처리
        - 엔티티를 열어 확인했다. 놓인 카드, 놓을 구역, 몇 번 칸에 몇 번 카드인지로 서로 달랐다
        - 합치지 않고 셋을 그대로 두되 한 묶음 아래로 넣었다
        - **이름이 비슷하다고 같은 것이 아니다.** 무엇을 담는지 열어 본다

2. 오타가 두 군데인데 서로 다른 폴더였다
    - 증상
        - opponent_field_crad_position 은 폴더 이름이 틀렸고 안의 파일 이름은 맞았다
        - opponent_field_card_scene 은 폴더 이름이 맞고 안의 파일 두 개가 틀렸다
        - 클래스 이름은 양쪽 다 맞았다. 그래서 부르는 쪽이 맞는 이름을 틀린 파일에서 가져오고 있었다
    - 원인
        - 오타를 폴더 이름 하나로만 봤다. 파일 이름까지 세지 않았다
    - 처리
        - 옮기면서 셋을 다 고쳤다. 클래스 이름이 안 바뀌어 코드 동작은 그대로다
        - **오타를 셀 때 폴더, 파일, 클래스를 따로 센다.** 셋이 다를 수 있다

3. 내 쪽과 상대 쪽의 짜임이 다르다
    - 증상
        - your_field 는 3파일이고 opponent_field 는 7파일이다. 내 쪽에는 그리는 코드와 서비스가 없다
        - your_field_area 에는 상대 쪽에 없는 프레임이 하나 더 있다
    - 원인
        - 내 필드 카드는 손패에서 끌어다 놓아 손패 쪽이 그리고, 상대 필드는 받아서 그려야 해 따로 있다
    - 처리
        - 억지로 맞추지 않았다. 실제로 하는 일이 달라서 생긴 차이다
        - **짝이 안 맞는다고 맞추지 않는다.** 왜 다른지 먼저 본다
