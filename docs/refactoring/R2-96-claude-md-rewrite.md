# Issue

1. 지침에 두 구조가 동시에 살아 있었다
    - 증상
        - [모든 기능 폴더는 entity/frame/repository/scene/renderer/service] 와
          [전투는 도메인·지금 판·그리는 쪽] 이 한 문서에 함께 있었다
    - 원인
        - R2-1 부터 R2-93 까지 지침을 안 고치고 백로그에만 결정을 쌓았다
        - 결정이 쌓일수록 지침과의 거리가 벌어졌다
    - 처리
        - 덧붙이지 않고 위계를 다시 잡았다. E+F+R 을 최상위에서 그리는 쪽 안으로 내렸다
        - **결정을 백로그에만 쌓으면 지침이 옛 구조를 계속 가르친다**

2. E+F+R 의 Entity 가 도메인 Entity 로 읽힌다
    - 증상
        - 지침에 `Entity — pure domain data` 라고 적혀 있었다
    - 원인
        - E+F+R 을 만들 때는 도메인이 따로 없었다. 그때는 맞는 말이었다
        - 지금은 도메인이 생겼고, 화면이 도메인 객체를 직접 받으면 안 된다
    - 처리
        - E+F+R 의 Entity 가 도메인 Entity 가 아님을 못 박고, 읽기 모델에서 만들어진다고 적었다
        - **말이 그대로여도 주변이 바뀌면 뜻이 달라진다**

3. 지침이 없는 파일을 가리키고 있었다
    - 증상
        - 가리키는 경로 아홉 중 다섯이 없었다. 숫자 넷도 달랐다
    - 원인
        - 폴더가 옮겨지고 코드가 지워져도 지침은 그대로였다
    - 처리
        - 새로 쓰면서 경로 열셋을 전부 열어 보고 확인했다
        - 무덤·로스트 존을 다루는 카드가 [여섯] 이라고 적혀 있었는데 세어 보니 열세 장이었다
        - **지침에 적은 숫자도 근거가 있어야 한다. 안 세면 틀린 채로 남는다**
