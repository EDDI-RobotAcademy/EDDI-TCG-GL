# Issue

1. 세 단계로 나눠 둔 것이 한 단계였다
    - 증상
        - 새 자리를 만들고, 본편을 옮기고, 확인용 화면을 옮기며 지우는 세 단계였다
        - 그런데 담은 것을 쓰는 곳이 없어 옮길 것이 없었다
    - 원인
        - R2-24 에서 판정할 때 넣는 곳으로 셌다. 읽는 곳은 안 셌다
        - 넣는 곳이 열넷이라 크게 보였다
    - 처리
        - 하나로 합쳐서 지웠다
        - **넣는 곳이 많아도 읽는 곳이 없으면 그것은 안 쓰는 것이다.** 크기는 넣는 곳으로 재지 않는다

2. 감췄다 다시 보일 때 가운데 맞추기가 풀렸다
    - 증상
        - 사용자가 필드 에너지 위 숫자의 자리가 이상하다고 했다
    - 원인
        - 화면 밖에 붙인 것을 감출 때 보이기 방식을 없음으로 바꾸고, 다시 보일 때 빈 값으로 되돌렸다
        - 그 조각들은 가운데를 맞추는 방식을 쓰는데, 빈 값을 넣으면 그것이 풀려 숫자가 왼쪽 위로 간다
    - 처리
        - 붙일 때 원래 쓰던 방식을 함께 적어 두고 그것으로 되돌린다
        - **감췄다 되돌릴 때 빈 값을 넣으면 원래 값이 아니라 기본값이 된다**
