# Issue

1. 셋을 한 티켓으로 묶은 근거가 옮기고 보니 없어졌다
    - 증상
        - 셋을 [쓴 뒤 눌러 고른다] 는 공통점으로 묶었다
        - 시체 폭발을 옮기자 그 공통점은 다 처리됐고, 남은 둘은 각자 다른 이유로 안 옮겨졌다
    - 원인
        - 네더 블레이드는 낼 때와 턴이 시작될 때 저절로 도는 것이 더 있다
        - 레오닉의 부름은 카드가 제 창을 든다 — 쪽 넘기기, 고른 것 표시, 확인 단추
        - 셋의 공통점은 셋 중 하나의 전부였을 뿐이다
    - 처리
        - 시체 폭발까지로 닫고 남은 둘을 각각 티켓으로 세웠다
        - **묶은 근거가 처리되면 남은 것을 다시 본다. 한 티켓 안에서 칸을 더 만들면 무엇 때문에 늘렸는지가 섞인다**

2. 같은 판정이 두 벌 있었다
    - 증상
        - 고르는 중에 누른 것이 무엇인지 찾는 코드가 시체 폭발과 네더 블레이드에 똑같이 있었다
    - 원인
        - 둘이 각자 제 상태를 들고 각자 판정했다
    - 처리
        - 한 자리로 뺐다. 화면이 [누른 것이 무엇인가] 를 찾아 주고 카드는 그것을 받는다
        - 본체를 먼저 보고 그다음 상대 유닛을 본다. 본체가 더 작아 순서가 바뀌면 겹친 자리에서 본체를 못 누른다
        - **찾는 일은 화면이, 무엇을 할지는 카드가. 그 선이 판정을 하나로 만든다**

3. 카드가 켠 테두리를 화면이 바로 껐다
    - 증상
        - 시체 폭발을 쓰면 무엇을 고를 수 있는지 알리는 붉은 테두리가 안 보인다
    - 원인
        - R2-117 에서 라우팅을 끌어올릴 때, 떨어뜨림 처리가 끝나면 테두리를 전부 걷게 해 뒀다
        - 시체 폭발은 그 처리 **안에서** 테두리를 켠다. 켜자마자 꺼졌다
        - 집을 때 켜는 것과 고르라고 켜는 것이 같은 테두리인데 끄는 시점이 다르다
    - 처리
        - 고르기가 시작됐으면 안 끄게 했다
        - **같은 것을 두 목적으로 쓰면, 끄는 시점도 목적마다 따로 정해야 한다**

4. 타입 하나를 두 카드가 나눠 쓰고 있었다
    - 증상
        - 시체 폭발의 고르기 타입을 지웠더니 네더 블레이드가 깨졌다
    - 원인
        - 한 타입을 둘이 썼는데 이름이 시체 폭발 것이었다
    - 처리
        - 되돌리고 네더 블레이드 쪽 이름으로 남겼다. 문법이 깨져 바로 드러났다
        - **지울 때 그것만 쓰는 것인지 본다. 이름이 한쪽 것이어도 둘이 쓸 수 있다**
