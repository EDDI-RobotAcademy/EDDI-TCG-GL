# [ETWGL-R2-105] 네더 블레이드를 전투 상태가 처리한다

선행: R2-104 │ 후행: R2-106 │ 산출물: 두 패시브의 전투 처리 │ Type: Rule │ Domain: Battle Ability

# Success criteria

1. 왜 하는지와 어디까지 할지를 정한다
    - 문제
        - 네더 블레이드는 전투가 안 다룬다. 화면이 두 패시브를 다 한다
        - 다섯 중 마지막이고, 앞의 넷과 다른 것이 둘 있다
          · 고르기 **앞에** 일이 먼저 일어난다. 첫 패시브가 터진 결과를 봐야 고를 수 있다
          · 능력이 능력을 부른다. 첫 패시브가 끝나면 둘째가 이어진다
        - R2-102 에서 이 카드 때문에 화면에 남겨 둔 임시 함수가 있다
    - 목적
        - 두 패시브를 전투가 하고 화면은 그린다
    - 기대 결과
        - 화면이 상대 유닛 체력을 직접 바꾸는 곳이 없어진다
    - 건드리지 않는 것
        - 검풍과 조각나는 그림 - 무엇을 보고 그리는지만 바꾼다
        - 턴마다 다시 터지는 것 - 부르는 자리는 그대로 둔다

2. 두 패시브가 각각 무엇을 하는지 본다

3. 고르기 앞에 일이 일어나는 것을 어떻게 다룰지 정한다

4. 옮기고, 화면은 일어난 일로 그리게 한다

5. 게임 동작이 달라지지 않았는지 확인한다
    - 유닛 내기, 첫 패시브, 둘째 패시브 고르기, 본체 고르기, 고르다 턴 종료, 암흑 에너지와 함께

# Issue

1. 고르기 앞에 일이 먼저 일어나므로 명령을 나눠야 했다
    - 증상
        - 앞의 카드들은 [쓴다] 한 번이면 끝났다. 이 카드는 내고, 터지고, 그 결과를 보고 고른다
    - 원인
        - 사용자가 하는 일이 둘이다. 유닛을 내는 것과, 결과를 보고 고르는 것
        - 그 사이에 게임이 스스로 움직인다
    - 처리
        - [유닛을 낸다] 와 [패시브를 터뜨린다] 를 나눴다. 화면이 연출을 기다린 뒤 둘째를 보낸다
        - 패시브를 터뜨리는 한 명령 안에서 첫째를 돌리고 이어서 기다리기 시작한다. 능력이 능력을 부르는 것이 그 안에 담긴다
        - **사이에 사용자가 봐야 할 것이 있으면 명령을 나눈다. 게임이 스스로 움직이는 것은 한 명령 안에 담는다**

2. 연출을 시작하기 전에 결과를 알아야 하는 자리가 있었다
    - 증상
        - 죽는 일격이면 갈라진 카드를 안 되돌린다. 연출을 시작할 때 이미 알아야 한다
    - 원인
        - 값은 연출을 기다리기 전에 다 바꾸는데, 이건 바꾸기 **전에** 결과를 물어야 한다
    - 처리
        - [이것을 고르면 쓰러지는가] 를 전투에 묻는 것을 만들었다. 묻기만 하고 아무것도 안 바꾼다
        - **바꾸기 전에 결과를 알아야 하는 자리가 있으면, 바꾸지 않고 묻는 방법을 따로 둔다**

3. 칠 것이 없으면 묻지 않아야 한다
    - 증상
        - 상대 필드가 비고 본체도 쓰러졌으면 고를 것이 없다
    - 원인
        - 전에는 화면이 세어서 건너뛰었다
    - 처리
        - 전투가 판단하고, 기다릴 것이 없으면 [묻기 시작했다] 를 안 돌려준다
        - 화면은 그것이 없으면 건너뛴다
        - **[물을 것이 있는가] 도 규칙이다. 화면이 세면 안 된다**
