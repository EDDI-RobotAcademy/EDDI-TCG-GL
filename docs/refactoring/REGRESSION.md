# 회귀 체크리스트

R2 리팩토링의 **모든** 티켓이 완료 전에 통과해야 하는 목록이다.
각 백로그는 이 문서를 **링크만** 하고 항목을 복사하지 않는다 (규칙 4).

현재 이 저장소에는 단위 테스트 러너가 없다 (`npm test`는 exit 1 스텁).
따라서 아래는 **수동 실행 절차**이며, 유일한 회귀 방어선이다.

```
npm run draw-field-energy-full-efr
```

---

## 자동 검증

- [ ] `npx tsc --noEmit` — 타입 오류 0
- [ ] `npm run depcruise` — 의존 방향 위반 0 (R2-3 완료 이후)

> GLSL 셰이더는 런타임 컴파일이라 `tsc`도 webpack도 잡지 못한다.
> 셰이더를 건드린 티켓은 아래 시각 항목을 반드시 육안 확인한다.

---

## 수동 회귀 — 9항목

### 1. 턴 진행
- [ ] 턴 종료 버튼 클릭 → `상대방의 턴입니다.` 배너
- [ ] `f` 키 → `당신의 턴입니다.` 배너, TURN 번호 +1, 필드 에너지 +1
- [ ] 모래시계가 턴 전환마다 재시작

### 2. 드래그 배치
- [ ] 손패 카드를 필드로 드래그 → 배치됨
- [ ] 필드 밖 드롭 → 손패로 스냅백
- [ ] 배치 직후 우클릭 → `이번 턴에 출격한 유닛으로 공격할 수 없습니다.`

### 3. 단일 공격
- [ ] 유닛 선택 → 우클릭 → 액티브 패널 → 공격 → 상대 유닛 클릭
- [ ] 상대 HP 감소, 0이면 사망 처리 및 재정렬
- [ ] 상대 본체 공격 시 본체 HP 감소

### 4. 광역기
- [ ] 광역 스킬 발동 → 상대 전체 피해
- [ ] `EveryField` 계열은 본체에도 피해

### 5. 단일기 (네더 블레이드 패시브 2)
- [ ] 검풍이 화면 전체로 날아가 지정 카드로 수렴
- [ ] 대상이 갈라지는 연출, 지면이 파이는 흔적
- [ ] 치명타 시 갈라짐 직후 사망 처리

### 6. 상태이상 (차갑게 불타는 암흑 에너지, 151)
- [ ] 부착 시 에너지 마크 아래 암흑 화염, 빙결 마크 세로 표기
- [ ] 피격 대상에 얼어붙고 불타는 오버레이
- [ ] 상대 턴 시작 시 암흑 화염 5 피해
- [ ] 빙결은 1회만, 다음 턴 재빙결 없음
- [ ] **광역기, 단일기, 패시브 경로에도 전부 적용** (ETWGL-R-53 회귀)

### 7. 본체 HP
- [ ] 내 본체, 상대 본체 핏방울이 지정 비율 위치에 표시
- [ ] 창 크기를 바꿔도 비율 유지

### 8. 타이머 만료
- [ ] 타겟팅 중 만료 → 아무것도 적용되지 않고 턴 넘어감
- [ ] 선택 완료 후 만료 → 동작을 모두 마친 뒤 턴 넘어가고 타이머 재시작

### 9. 존 팝업
- [ ] 내/상대 무덤, 내/상대 로스트 존 클릭 → 각각의 안내 배너
- [ ] 팝업 페이지 이동 동작
