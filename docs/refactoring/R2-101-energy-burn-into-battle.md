# [ETWGL-R2-101] 에너지 번을 전투 상태가 처리한다

선행: R2-85 │ 후행: R2-102 │ 산출물: 에너지 번의 전투 처리 │ Type: Rule │ Domain: Battle Ability

# Success criteria

1. 왜 하는지와 어디까지 할지를 정한다
    - 문제
        - 에너지 번은 전투가 안 다룬다. 화면이 에너지를 빼고 피해를 주고 무덤으로 보낸다
        - 실제 대전에서는 서버가 셈할 일인데 클라이언트가 하고 있다 (규칙 25)
        - R2-85 에서 [지금 모양 그대로 된다] 고 판정한 카드다. 새로 만들 것이 없다
    - 목적
        - 에너지 번의 판정을 전투로 옮기고, 화면은 일어난 일을 받아 그리기만 한다
    - 기대 결과
        - 화면이 이 카드의 숫자를 안 든다
    - 건드리지 않는 것
        - 연출이 어떻게 생겼는지 - 무엇을 보고 그리는지만 바꾼다
        - 나머지 카드 셋 - R2-102 부터 차례로 한다

2. 화면이 지금 무엇을 정하는지 본다

3. 전투가 그것을 하려면 무엇이 없는지 본다

4. 옮기고, 화면은 일어난 일만 보게 한다

5. 게임 동작이 달라지지 않았는지 확인한다
    - 에너지 번 — 에너지 둘, 하나, 없는 유닛 각각

# Issue

1. 에너지가 빠졌다고 알릴 방법이 없었다
    - 증상
        - 일어난 일 여덟 가지에 [에너지가 붙었다] 는 있는데 [빠졌다] 가 없었다
    - 원인
        - 지금까지 에너지는 붙이기만 했다. 빼는 카드가 이 카드가 처음이다
    - 처리
        - 빠졌다는 것을 더했다. 종족을 안 가리고 빼므로 수만 알린다
        - **옮기려는 일이 지금까지 없던 방향이면 알릴 방법부터 없는지 본다**

2. 화면이 숫자를 들고 있었다
    - 증상
        - 화면이 [못 없앤 하나당 얼마] 를 카드 능력에서 꺼내 들고 있었다
    - 원인
        - 화면이 계산했으니 화면이 숫자를 알아야 했다
    - 처리
        - 전투로 옮기니 화면에서 그 숫자가 필요 없어졌다. 지웠다
        - **판정을 옮기면 그 판정에 쓰이던 숫자도 따라 옮겨져야 한다. 남아 있으면 덜 옮긴 것이다**

## 죽음의 낫과 같은 모양이 됐다

```
카드를 떨어뜨림
  → 명령을 보낸다
  → 전투가 판정하고 일어난 일을 돌려준다
```
