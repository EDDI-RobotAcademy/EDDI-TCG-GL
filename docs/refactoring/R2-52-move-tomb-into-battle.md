# [ETWGL-R2-52] 무덤을 전투 상태 안으로 옮긴다

선행: R2-51 │ 후행: R2-53 │ 산출물: Battle 이 내 무덤과 상대 무덤을 들고 있다 │ Type: Rule │ Domain: Battle Tomb

# Success criteria

1. 왜 하는지와 어디까지 할지를 정한다
    - 문제
        - 내 무덤과 상대 무덤이 전투 밖의 저장소에 따로 있다
        - 재접속하면 무덤에 무엇이 어떤 차례로 쌓였는지를 따로 되돌려야 한다
    - 목적
        - 무덤을 전투 한 판 안으로 옮긴다
    - 기대 결과
        - 전투를 통째로 적으면 무덤에 쌓인 것도 함께 적힌다
    - 건드리지 않는 것
        - 무덤을 그리는 것과 눌렀을 때 열리는 것 - 화면이다. 값이 아니다
        - 로스트 존 - 생김새가 같아도 다른 것이다. R2-53
        - 무덤에서 꺼내는 길 - 부활하는 카드가 아직 없다. 나오면 그때 낸다

2. 무덤과 로스트 존을 합치지 않는다
    - 지금 둘은 코드가 같다. 쌓기, 보기, 비우기뿐이다
    - 그러나 다른 이유로 바뀐다. 무덤은 부활할 수 있고 로스트 존은 못 한다
    - 부활을 다루는 카드가 붙기 시작하면 무덤만 바뀐다
    - 지금 합치면 그때 조건을 넣거나 다시 갈라야 한다

3. 내 무덤과 상대 무덤은 안쪽을 함께 쓴다
    - 쌓는 방식은 양쪽이 같다
    - 다른 것은 누구 것이냐이고, 그것은 전투가 낸 길에서 갈린다
    - 시체 폭발은 아군을 내 무덤으로 보낸다. 길이 갈려 있어야 그 카드를 적을 수 있다

4. 쓰던 곳을 바꾸고 옛것을 지운다
    - 무덤을 쓰는 곳은 확인용 화면 하나다. 쌓는 곳 여섯, 보는 곳 넷
    - 화면에 그리는 쪽은 건드리지 않는다

5. 게임 동작이 달라지지 않았는지 확인한다
    - 내 무덤 열기, 상대 무덤 열기, 카드를 무덤으로 보내기

# Issue

1. 코드가 같은 둘을 합치고 싶어진다
    - 증상
        - 무덤과 로스트 존의 저장소가 글자까지 같았다. 한 벌로 만들고 싶어진다
    - 원인
        - 백 장 중 열두 장만 만들어져 있어서, 둘을 가르는 카드가 아직 코드에 없다
    - 처리
        - 합치지 않았다. 무덤은 부활할 수 있고 로스트 존은 못 한다. 다른 이유로 바뀐다
        - **지금 같아 보이는 것은 가르는 것이 아직 안 만들어졌기 때문일 수 있다**

2. 안쪽을 함께 쓰는 것과 밖으로 낸 길을 합치는 것은 다르다
    - 증상
        - 내 무덤과 상대 무덤을 한 벌로 쓰면 양쪽 구분이 사라지는 것처럼 보인다
    - 원인
        - 담는 그릇을 함께 쓰는 것과, 부르는 길을 함께 쓰는 것을 같은 일로 봤다
    - 처리
        - 그릇은 한 벌, 길은 두 벌로 냈다. 어느 쪽 무덤인지는 부르는 길에서 갈린다
        - **함께 쓸 것과 갈라 둘 것을 층으로 나눈다.** 아래는 함께, 위는 따로
