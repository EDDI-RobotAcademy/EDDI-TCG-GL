# [ETWGL-R2-58] 카드 능력 판정표

R2-58 의 붙임 자료다. 만들어진 카드 열두 장이 무엇을 하는지 카드 설명으로 적었다.

## 카드 열둘

| 카드 | 종류 | 무엇을 고르는가 | 무엇이 일어나는가 | 얼마 |
| --- | --- | --- | --- | --- |
| 죽음의 낫 (8) | 아이템 | 상대 유닛 하나 | 신화 미만이면 즉사, 신화면 피해 | 30 |
| 에너지 번 (9) | 아이템 | 상대 유닛 하나 | 붙은 에너지가 적을수록 피해, 있으면 에너지를 뺏는다 | 없으면 20, 하나면 10 + 하나 뺏음, 둘 이상이면 둘 뺏음 |
| 사기 전환 (35) | 아이템 | 내 필드 유닛 하나 | 그 유닛을 무덤으로 보내고 필드 에너지를 얻는다 | 체력을 5로 나눈 몫 |
| 넘쳐 흐르는 사기 (2) | 서포트 | 내 필드 유닛 하나 | 덱에서 죽음의 에너지를 꺼내 그 유닛에 붙인다 | 최대 두 장 |
| 차갑게 불타는 암흑 에너지 (151) | 에너지 | 내 필드 유닛 하나 | 종족 에너지 하나를 주고, 그 유닛의 공격과 스킬에 암흑 화염과 빙결을 붙인다 | 암흑 화염 매 턴 5 |
| 죽음의 에너지 (93) | 에너지 | 내 필드 유닛 하나 | 종족 에너지 하나를 붙인다 | 하나 |
| 망자의 늪 (20) | 서포트 | 내 필드 전체 | 덱에서 카드를 뽑는다 | 석 장 |
| 파멸의 계약 (25) | 아이템 | 상대 필드 전체 | 살아 있는 상대 유닛 전부와 본체에 피해, 내 덱에서 한 장을 로스트 존으로 | 피해 15, 한 장 |
| 죽음의 대지 (36) | 아이템 | 상대 필드 전체 | 상대 필드 에너지를 깎는다. 0 아래로는 안 내려간다 | 둘 |
| 레오닉의 부름 (30) | 서포트 | 내 필드 전체 | 덱에서 영웅 이하 유닛을 골라 손패로, 이 카드는 무덤으로, 덱을 섞는다 | 두 장 |
| 시체 폭발 (33) | 아이템 | 내 필드의 언데드 유닛 하나 | 그 유닛을 제물로 바치고, 이어서 상대를 두 번 고른다. 같은 것을 두 번 골라도 된다 | 한 번에 10, 두 번 |
| 마검의 지배자 네더 블레이드 (19) | 유닛 | 없다. 등장하면 저절로 | 첫 패시브는 상대 유닛 전체에 피해, 이어서 두 번째 패시브가 상대 하나를 고르게 한다 | 전체 10, 하나 20 |

## 무엇을 고르는가 — 여섯 가지

| 고르는 방식 | 쓰는 카드 |
| --- | --- |
| 상대 유닛 하나 | 죽음의 낫, 에너지 번 |
| 내 필드 유닛 하나 | 사기 전환, 넘쳐 흐르는 사기, 죽음의 에너지, 차갑게 불타는 암흑 에너지 |
| 내 필드의 언데드 유닛 하나 | 시체 폭발 |
| 내 필드 전체 | 망자의 늪, 레오닉의 부름 |
| 상대 필드 전체 | 파멸의 계약, 죽음의 대지 |
| 고르지 않는다 | 네더 블레이드 |

**세 번째가 두 번째의 좁은 판이다.** 조건이 종족 하나뿐이라 값으로 적을 수 있다.

## 무엇이 일어나는가 — 아홉 가지

| 일어나는 일 | 쓰는 카드 |
| --- | --- |
| 피해를 준다 | 죽음의 낫, 에너지 번, 파멸의 계약, 시체 폭발, 네더 블레이드 |
| 즉사시킨다 | 죽음의 낫 |
| 무덤으로 보낸다 | 사기 전환, 시체 폭발, 레오닉의 부름 |
| 로스트 존으로 보낸다 | 파멸의 계약 |
| 덱에서 뽑는다 | 망자의 늪 |
| 덱에서 골라 손패로 | 레오닉의 부름, 넘쳐 흐르는 사기 |
| 덱을 섞는다 | 레오닉의 부름 |
| 필드 에너지를 얻거나 깎는다 | 사기 전환, 죽음의 대지 |
| 카드에 에너지를 붙인다 | 넘쳐 흐르는 사기, 죽음의 에너지, 차갑게 불타는 암흑 에너지 |
| 상태를 붙인다 | 차갑게 불타는 암흑 에너지 |

## 값으로 되는 것과 안 되는 것

### 값으로 되는 여덟

| 카드 | 왜 되는가 |
| --- | --- |
| 죽음의 대지 | 고르는 것 하나, 일어나는 일 하나, 숫자 하나 |
| 망자의 늪 | 같음 |
| 죽음의 에너지 | 같음 |
| 파멸의 계약 | 일어나는 일이 둘이지만 각각 숫자 하나다 |
| 사기 전환 | 숫자가 대상의 체력에서 나온다. [무엇을 5로 나눈 몫] 을 값으로 적을 수 있다 |
| 넘쳐 흐르는 사기 | 덱에서 특정 카드를 최대 몇 장. 둘 다 값이다 |
| 레오닉의 부름 | 고르는 조건이 등급 이하 + 종류. 둘 다 값이다 |
| 죽음의 낫 | 등급에 따라 갈리지만 갈림이 하나뿐이다. [신화면 얼마, 아니면 즉사] |

### 값으로 안 되는 넷

| 카드 | 왜 안 되는가 |
| --- | --- |
| 에너지 번 | 붙은 에너지 수에 따라 피해와 뺏는 양이 함께 달라진다. 표가 셋이다 |
| 시체 폭발 | 제물을 바친 뒤 고르기가 한 번 더 일어난다. 고르기가 두 단계다 |
| 네더 블레이드 | 첫 패시브가 끝나면 두 번째 패시브가 저절로 이어진다. 능력이 능력을 부른다 |
| 차갑게 불타는 암흑 에너지 | 붙인 뒤 그 유닛의 모든 공격과 스킬에 따라붙는다. 한 번 일어나고 끝이 아니다 |

**넷의 공통점은 [한 번 일어나고 끝나지 않는다] 는 것이다.**

```
에너지 번    대상의 상태를 보고 무엇을 할지 정한다
시체 폭발    고르기 → 일어남 → 고르기 → 일어남
네더 블레이드  능력이 끝나면 다음 능력이 시작된다
암흑 에너지   붙여 두면 나중에 일어나는 일에 따라붙는다
```

## 이것이 뜻하는 것

카드를 값으로 적으려면 **[고르기 한 번 → 일어남 한 번] 을 넘어서는 모양**이 필요하다.

```
필요한 모양
  고르기와 일어남을 여러 번 이어 붙일 수 있어야 한다
  대상의 상태를 보고 갈라질 수 있어야 한다
  일어남이 끝난 뒤 다음 일어남을 부를 수 있어야 한다
  붙여 두었다가 나중에 따라붙는 것을 적을 수 있어야 한다
```

앞의 셋은 [단계를 나열한다] 로 풀린다. **마지막 하나는 다르다.** 그것은 능력이 아니라
유닛에 붙는 상태이고, 상태가 나중의 일어남을 바꾸는 것이다. 능력 정의와 따로 봐야 한다.
