# Issue

1. R2-46 에서 만든 규칙이 셋에만 붙어 있었다
    - 증상
        - 글자로 만든 그림을 놓아주는 규칙을 만들었는데, 스무 곳이 안 지키고 있었다
    - 원인
        - 그때는 만드는 곳을 세어 표시를 붙이고, 놓아주는 곳은 그때 걸린 셋만 고쳤다
    - 처리
        - 모으니 나머지가 함께 따라왔다
        - **규칙을 만들 때 그 규칙을 지켜야 하는 곳을 다 세지 않으면, 규칙이 몇 곳에만 붙는다**

2. 티켓은 연출 이야기였는데 렌더러에도 있었다
    - 증상
        - 연출 열을 모으고 나니 같은 모양이 렌더러 열셋에 더 있었다
    - 원인
        - R2-46 에서 연출을 보다 발견해서 연출 이야기로 적혔다
    - 처리
        - 같은 모양을 세어 함께 모았다
        - **R2-73 에서 적은 [한 곳에서 찾은 문제는 다른 곳에도 있는지 센다] 가 또 맞았다**

3. 줄바꿈만 달라 한 번에 안 잡혔다
    - 증상
        - 같은 코드인데 중괄호 줄바꿈이 달라 무늬가 안 맞았다. 넷이 남았다
    - 원인
        - 무늬로 찾을 때 줄바꿈까지 똑같아야 잡힌다
    - 처리
        - 남은 것을 다시 세어 무늬를 하나 더 만들었다
        - **무늬로 셀 때는 세고 나서 남은 것이 있는지 다시 센다**
