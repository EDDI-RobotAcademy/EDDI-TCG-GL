# Issue

1. 남긴 뜻을 추측해 적을 뻔했다
    - 증상
        - 무엇을 위한 자리인지 코드에 없어서, 읽어서 알 수 있는 것이 [카드 능력 표에서 겨냥 방식으로 뽑아 온다] 뿐이었다
    - 원인
        - 남긴 사람만 아는 것이다. 코드에 안 적혀 있으면 읽어서 못 알아낸다
    - 처리
        - 추측한 주석을 적지 않고 물었다. 답이 [손패에서 지금 쓸 수 있는 카드 표시] 였고 그대로 적었다
        - **주석을 추측해 적으면 틀린 채로 굳는다.** 코드와 달리 주석은 틀려도 아무것도 안 터진다

2. 남긴 뜻은 맞는데 남긴 모양이 틀렸다
    - 증상
        - 그 일을 하려고 남긴 목록 둘이, 정작 그 일에 못 쓰는 모양이었다
    - 원인
        - 카드 번호 목록은 [무엇을 겨냥하나] 로 한 번 가른 것이다. [지금 쓸 수 있나] 는 그 위에 [내 차례인가] [겨냥할 것이 있나] 가 더 붙는다
        - 겨냥 방식이 여섯인데 목록이 둘이라 절반도 못 덮는다
    - 처리
        - 목록을 지우고, 무엇이 맞는 모양인지를 주석에 적었다
        - **자리를 남길 때는 [무엇을 하려는지] 와 [어떻게 하려는지] 를 같이 남긴다.** 뜻만 남기면 다음 사람이 남은 모양을 그대로 쓴다

## 지금 모양으로 안 되는 이유

| | |
| --- | --- |
| 겨냥 방식 여섯 중 둘만 집어 온다 | 손패에서 쓰는 카드 열하나 중 여섯만 덮었다 |
| 겨냥 방식이 늘면 목록을 더해야 한다 | 카드가 늘 때마다 화면 파일이 커진다 |
| [무엇을 겨냥하나] 만 답한다 | [지금 쓸 수 있나] 는 그 위에 둘이 더 붙는다 |

두 목록에 실제로 들어오던 것: 상대를 겨냥하는 것 둘(죽음의 낫, 에너지 번), 아군을 겨냥하는
것 넷(사기 전환, 넘쳐 흐르는 사기, 죽음의 에너지, 차갑게 불타는 암흑 에너지). 여섯 다 손패에서
쓰는 카드가 맞다. 빠진 다섯은 겨냥 방식이 다르다 — 내 필드 전체 둘, 상대 필드 전체 둘,
종족이 정해진 아군 하나. 필드에 내는 유닛 카드 셋도 손패에서 쓰는 것이다.

## 쓸 수 있는지는 셋이 함께 정한다

| 조건 | 어디가 아나 |
| --- | --- |
| 내 차례인가 | 전투가 안다. 읽기 창구가 이미 내놓는다 |
| 전투가 받아 주는가 | 카드마다 다르다. 그 카드가 안다 |
| 겨냥할 것이 있는가 | 카드가 제 조건을 들고 화면이 센다. **이미 돌고 있다** |

셋째는 집었을 때 테두리를 씌우는 자리가 이미 세고 있다 — 씌울 것이 없으면
`[pickup] cardId=33 놓을 수 있는 아군이 없다` 를 적는다. 만들 때 그 길을 다시 안 만든다.
