# Issue

1. 미리 재는 것이 왜 문제인지가 설명에 적혀 있었다
    - 증상
        - 자리를 담는 파일에 [한 곳은 미리 재고 나머지는 쓸 때마다 잰다. 그래서 창 크기를 바꾼 뒤 어긋난다] 고 적혀 있었다
        - 그러면서 [언제 재는지를 맞추는 일은 여기서 하지 않는다] 로 끝난다
    - 원인
        - R2-43 에서 발견했지만 그 티켓의 범위가 아니라 적어만 뒀다
    - 처리
        - 이번에 맞추고 그 설명을 고쳤다
        - **알면서 안 고친 것은 설명에 적어 둔다.** 다음 사람이 찾아 헤매지 않는다

2. 미리 재는 것과 쓸 때마다 재는 것은 값이 같아 보인다
    - 증상
        - 두 계산이 같은 함수를 부른다. 코드만 보면 같은 값이 나온다
    - 원인
        - 다른 것은 언제 부르느냐다. 화면 크기가 바뀌기 전인지 후인지
    - 처리
        - 미리 재는 쪽을 없앴다
        - **같은 계산이라도 언제 부르느냐가 다르면 다른 값이다**
