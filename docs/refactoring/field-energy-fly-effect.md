        - 필드 에너지를 유닛에 붙이면 숫자만 바뀌고 아무것도 날아오지 않았다

## 무엇이 언제 바뀌나

| 시점 | 바뀌는 것 |
| --- | --- |
| 누른 순간 | 전투가 붙인다. 남은 개수가 줄고 초록 테두리가 꺼진다 |
| 떠나는 0.6초 | 표기 자리에서 고리 둘이 안으로 빨려 들고 터져 나간다 |
| 나는 0.6초 | 알갱이 하나가 곡선을 그려 유닛으로 간다 |
| 닿는 순간 | 카드의 에너지 숫자가 오른다. 충격파와 섬광 |

붙는 것은 **이미 참이다.** 전투가 먼저 정하고 연출은 그것을 시간에 걸쳐 보여 준다. 그래서
남은 개수는 떠날 때 줄고 카드 숫자는 닿을 때 오른다. 연출이 무엇을 정하지 않는다.

## 겹쳐 날아가는 것

기다리지 않는다. 빠르게 여러 번 누르면 알갱이 여럿이 동시에 난다. 뒤늦게 닿은 것이 자기가
들고 있던 옛 숫자로 되돌려 쓰는 일은 카드 숫자 쪽이 이미 막고 있다 (규칙 28). 이번에 막는
장치를 새로 만들지 않았고, 있던 것이 그대로 맞았다.
