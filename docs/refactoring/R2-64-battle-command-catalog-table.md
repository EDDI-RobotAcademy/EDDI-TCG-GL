# [ETWGL-R2-64] 사용자가 하는 일과 일어나는 일 판정표

R2-64 의 붙임 자료다. 지금 확인용 화면이 하는 일을 [밖에서 오는 것] 단위로 갈랐다.

## 밖에서 오는 것 — 여덟

사용자가 하는 일 하나가 하나다. 화면을 만지는 일(창 크기 바꾸기, 팝업 열기,
쪽 넘기기)은 전투와 무관하므로 여기 없다.

| 밖에서 오는 것 | 무엇이 함께 온다 | 지금 화면이 조립하는 줄 |
| --- | --- | --- |
| 턴을 끝낸다 | 없다 | 한 줄. 이미 됐다 |
| 상대 턴을 끝낸다 | 없다 | 한 줄. 이미 됐다 |
| 덱에서 한 장 뽑는다 | 없다 | 셋 |
| 손패 카드를 필드에 낸다 | 어느 카드인가 | 여섯 |
| 카드를 유닛에 쓴다 | 어느 카드, 어느 유닛 | 카드마다 넷에서 열 |
| 카드를 필드 전체에 쓴다 | 어느 카드, 내 쪽인가 상대 쪽인가 | 카드마다 셋에서 여덟 |
| 유닛으로 공격한다 | 어느 유닛, 무엇을 | 다섯 |
| 유닛의 스킬을 쓴다 | 어느 유닛, 몇 번째 스킬, 무엇을 | 여섯 |

## 돌려줄 것 — 다섯

전투 상태가 무슨 일이 있었는지 알려 준다. 화면은 이것만 보고 그린다.

| 돌려줄 것 | 언제 | 화면이 이것으로 하는 일 |
| --- | --- | --- |
| 안 된다, 이유는 이것 | 쓸 수 없는 카드를 냈을 때 등 | 카드를 제자리로 돌린다. 안내 문구 |
| 카드가 어디에서 어디로 갔다 | 손패에서 필드로, 무덤으로 | 카드를 옮기거나 감춘다. 자리를 다시 잡는다 |
| 무엇이 얼마나 다쳤다 | 피해를 줬을 때 | 숫자를 고치고 흔들거나 번쩍인다 |
| 무엇이 쓰러졌다 | 체력이 0 이 됐을 때 | 감추고 자리를 다시 잡는다 |
| 값이 이만큼 바뀌었다 | 필드 에너지, 턴 수 | 숫자를 다시 그린다 |

## 왜 [무슨 일이 있었나] 를 돌려주는가

화면이 지금 상태를 다시 읽어서 그리면 될 것 같지만 안 된다. **무엇이 달라졌는지를
모르면 연출을 못 고른다.**

```
지금 상태만 보면    상대 유닛이 넷이다
무슨 일이 있었나     3번이 죽음의 낫에 베여 쓰러졌다   →  베는 연출을 튼다
```

그리고 다시 읽기만 하면 **한 번에 여러 가지가 일어났을 때 순서를 모른다.**
파멸의 계약은 여럿을 한꺼번에 때리는데, 누가 먼저 쓰러졌는지가 연출 순서를 정한다.

## 규칙

```
받는 것    하나만 보낸다. 여러 줄로 나눠 시키지 않는다
판단       전투 상태가 한다. 되는지 안 되는지도 거기서 나온다
돌려주는 것  무슨 일이 있었는지를 일어난 차례대로
화면       돌려받은 것만 보고 그린다. 순서를 조립하지 않는다
```

## 안 되는 것

**연출 중간에 값이 바뀌는 카드가 있다.** 시체 폭발은 날아온 것이 하나씩 맞을 때마다
피해가 들어간다. 전투 상태가 결과를 한 번에 돌려주면 화면이 그 사이를 못 만든다.

```
받는 것    시체 폭발을 두 곳에 쓴다
돌려주는 것  첫 번째가 이렇게 됐고, 두 번째가 이렇게 됐다
화면       첫 번째 것이 맞을 때 첫 번째 결과를 쓰고, 두 번째 것이 맞을 때 두 번째를 쓴다
```

**일어난 차례대로 돌려주면 화면이 그 차례를 연출에 나눠 붙일 수 있다.** 그래서
돌려주는 것을 하나가 아니라 목록으로 둔다.

## 지금 할 것과 나중에 할 것

| 밖에서 오는 것 | 언제 |
| --- | --- |
| 턴을 끝낸다, 상대 턴을 끝낸다 | 이미 됐다 (R2-63) |
| 손패 카드를 필드에 낸다 | R2-65 |
| 덱에서 한 장 뽑는다 | R2-65 에 함께. 손패에 들어오는 같은 길이다 |
| 카드를 유닛에 쓴다, 카드를 필드 전체에 쓴다 | R2-66 |
| 유닛으로 공격한다, 유닛의 스킬을 쓴다 | R2-67 |
