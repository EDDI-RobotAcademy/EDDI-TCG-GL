# [ETWGL-R2-73] 아직 못 만든 화면으로 가는 버튼이 준비 중임을 알리게 한다

선행: — │ 후행: R2-74 │ 산출물: 로비와 상점의 안내 문구 │ Type: Rule │ Domain: Lobby

# Success criteria

1. 왜 하는지와 어디까지 할지를 정한다
    - 문제
        - 로비의 1대1 대전 버튼이 등록되지 않은 길로 보낸다
        - 없는 길로 보내면 로비로 되돌아온다. 눌러도 아무 일이 안 일어난 것처럼 보인다
        - 상점의 카드 뽑기 버튼 넷도 같다. 그쪽은 상점에서 튕겨 나간 것처럼 보인다
    - 목적
        - 아직 못 만든 화면으로 가는 버튼이 준비 중임을 알리게 한다
    - 기대 결과
        - 눌러도 화면이 안 바뀌고, 왜 안 바뀌는지가 보인다
    - 건드리지 않는 것
        - 1대1 대전과 카드 뽑기 화면을 만드는 일 - 서버가 있어야 한다
        - 되는 버튼 셋 - 보유 카드, 상점, 테스트

2. 어디서 어디로 가는지 다 센다
    - 로비만 보면 안 된다. 화면을 옮기는 곳을 전부 센다
    - 등록된 길과 대 보고 없는 것을 찾는다

3. 어떻게 알릴지 정한다
    - 전투 화면이 쓰는 안내 문구가 이미 있다. 그것을 쓴다
    - 3초 뒤에 저절로 사라진다

4. 화면을 떠날 때 치운다
    - 안내 문구는 화면 밖에 붙는다. 안 치우면 다음 화면에 남는다

5. 게임 동작이 달라지지 않았는지 확인한다
    - 1대1 대전, 카드 뽑기 안내 문구
    - 되는 버튼들은 전과 같이 가는지

# Issue

1. 로비만이 아니었다
    - 증상
        - 티켓은 로비 이야기였는데, 세어 보니 상점에 넷이 더 있었다
    - 원인
        - 처음 이 문제를 찾은 곳이 로비라서 로비 이야기로 적혔다
    - 처리
        - 화면을 옮기는 곳을 전부 세고 등록된 길과 대 봤다. 아홉 중 다섯이 없는 길이었다
        - **한 곳에서 찾은 문제는 같은 모양이 다른 곳에도 있는지 센다**

2. 없는 길로 보내면 조용히 되돌아온다
    - 증상
        - 눌러도 아무 일이 안 일어난다. 상점에서는 로비로 튕겨 나간다
    - 원인
        - 길을 못 찾으면 로비로 되돌리게 되어 있다. 그 자체는 맞는 처리다
        - 다만 부르는 쪽이 없는 길인 줄 모르고 부른다
    - 처리
        - 안 만든 화면으로 가는 버튼은 아예 안 보내고 알린다
        - **되돌리는 처리가 있다고 아무 길이나 불러도 되는 것이 아니다**

3. 제목이 무엇을 하는지 안 가리켰다
    - 증상
        - 원래 제목이 [로비의 게임 입장 버튼이 눌리도록 등록되지 않은 경로 정리] 였다
        - 무엇을 정리한다는 것인지, 정리하면 무엇이 되는지가 안 보인다
    - 원인
        - 문제를 적었지 하려는 일을 안 적었다
    - 처리
        - [아직 못 만든 화면으로 가는 버튼이 준비 중임을 알리게 한다] 로 바꿨다
        - **제목은 문제가 아니라 하려는 일을 적는다**
