# Issue

1. 넷 중 하나만 재는 시점이 달랐다
    - 증상
        - CardSkillMotion 은 private static readonly 로 적혀 있어 파일을 읽을 때 한 번만 잰다
        - AttackAnimationV2 와 시나리오는 부를 때마다 잰다
        - 창 크기를 바꾸고 스킬을 쓰면 카드가 서는 자리가 서로 어긋난다
    - 원인
        - 원본 SkillPanelAnimator 때부터 그랬다. R2-15 에서 갈라내며 그대로 옮겼다
    - 처리
        - 이번에 맞추지 않았다. 맞추면 창 크기를 바꾼 뒤의 동작이 달라지고, 그건 숫자를 모으는 일과 다른 일이다
        - 부르는 쪽이 화면 높이를 넘기게 해서 각자 지금 시점을 유지했다
        - **한 곳으로 모을 때 값이 같은지와 언제 재는지를 따로 본다.** 값만 보면 시점 차이가 묻힌다

2. 숫자로 찾지 않았으면 네 곳 중 둘을 놓쳤다
    - 증상
        - R2-15 Review 에는 두 곳이라고 적었다. 실제로는 네 곳이었다
    - 원인
        - 이름으로 찾았다. 네 곳이 각각 SKILL_POSITION_Y, skillPanelY 로 다르게 부른다
    - 처리
        - 0.78221649 라는 숫자로 찾아 넷을 다 찾았다
        - **같은 값을 쓰는 곳은 값으로 찾는다.** 이름은 곳마다 다르다
