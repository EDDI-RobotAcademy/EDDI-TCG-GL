# [ETWGL-R2-44] 덱 편성 화면이 전투 연출을 만들지 않게 한다

선행: R2-43 │ 후행: R2-45 │ 산출물: 없음 (삭제와 연결 변경) │ Type: Rule │ Domain: Battle Animation

# Success criteria

1. 왜 하는지와 어디까지 할지를 정한다
    - 문제
        - 검으로 본체를 칠 때 화면을 가르는 연출이 한 번만 만들어지는데, 전투 화면과 덱 편성 화면 둘 다 그것을 만들려 한다
        - 먼저 부른 쪽의 화면에 묶인다. 덱이 먼저 묶이면 전투에서 덱 화면을 찍어 가른다
    - 목적
        - 전투 연출은 전투 화면만 만들게 한다
    - 기대 결과
        - 어느 화면을 먼저 들르든 화면 가르기가 전투 화면을 찍는다
    - 고치기 전에 확인한 것
        - 중간에 있던 것은 껍데기였다. 등록된 연출이 하나뿐이고 그 하나가 하는 일이 기록 한 줄이다
        - 부르는 함수도 노출만 되어 있고 부르는 곳이 없다
        - 실제로 하는 일은 생성자가 화면 가르기를 만드는 것뿐이었다
    - 건드리지 않는 것
        - 화면 가르기 연출 자체 - 만드는 곳만 바꾼다
        - 덱 편성 화면이 그리는 것 - 뺀 넷은 아무것도 안 그린다

2. 어떻게 얽혀 있는지 짚는다

```
전투 화면      만들기(자기 화면)  ┐
덱 편성 화면    만들기(자기 화면)  ┘  →  처음 부른 것만 만들어진다
                                        └ 화면 가르기가 그 화면에 묶인다

공격 연출      꺼내 쓰기          →  묶인 화면을 찍어 가른다
```

3. 껍데기를 없애고 직접 잇는다
    - 중간에 있던 것을 지우고 전투 화면이 화면 가르기를 직접 만들게 한다
    - 껍데기만 두고 덱 쪽만 빼면 [이게 뭐 하는 것인지] 를 다음에 또 묻게 된다
    - 그 껍데기가 쓰던 연출 종류 목록도 함께 없앤다. 그것만 쓰던 것이다

4. 덱 편성 화면에서 뺀다
    - 만들기, 필드, 꺼내 주는 함수, 읽어오기 넷을 뺀다
    - 넷 다 아무것도 안 그린다. 덱 화면에 보이는 것이 달라지지 않는다

5. 게임 동작이 달라지지 않았는지 확인한다
    - 검으로 본체를 칠 때 화면이 갈라지는지
    - 덱 편성 화면이 전과 같은지

# Issue

1. 고친 것이 지금은 터지지 않는 자리였다
    - 증상
        - 덱 편성을 먼저 들른 뒤 전투로 가는 경로를 확인하려 했는데 그런 경로가 없었다
        - 덱 편성 화면은 라우터에 없다. 확인용 화면으로만 뜬다
        - 확인용 화면은 각자 혼자 도는 서버라 두 화면이 한 페이지에 못 뜬다
    - 원인
        - 구조상 그렇게 될 수 있는 것이지 지금 그러고 있는 것은 아니었다
    - 처리
        - 그대로 고쳤다. 덱 편성이 나중에 라우터에 붙으면 그때 터진다
        - 확인은 [검으로 본체 공격이 그대로 되는가] 와 [덱 화면이 그대로인가] 둘로 대신했다
        - **터지기 전에 막은 것은 터지는 것을 보여줄 수 없다.** 그럴 때는 무엇이 안 깨졌는지로 확인한다

2. 덱 화면이 배경만 나오는 것이 이번 변경 때문인지 물었다
    - 증상
        - 덱 편성 확인용 화면을 띄우니 배경과 음악만 나왔다
    - 원인
        - 원래 그렇다. 덱 화면을 그리는 코드가 배경 한 장 붙이는 것뿐이다. 커밋된 것과 지금이 같다
        - 이 화면은 새 방식으로 다시 만드는 중이고 배경까지만 되어 있다. 덱 화면을 실제로 그리는 것은 다른 확인용 화면 둘이다
    - 처리
        - 커밋된 것과 맞대어 확인했다. 이번 변경은 8줄 삭제뿐이고 그 넷은 아무것도 안 그린다
        - **뺀 것이 무엇을 하던 것인지 먼저 본다.** 화면이 허전하다고 방금 뺀 것 때문인 것은 아니다
