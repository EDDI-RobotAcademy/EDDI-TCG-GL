# Issue

1. 옮기는 방법이 셋인데 곡선은 둘이었다
    - 증상
        - 네 벌이 TWEEN, 자체 tween, 매 프레임 직접 계산으로 셋으로 갈려 있었다
        - 방법이 다르면 곡선도 다를 것으로 봤다
    - 원인
        - 확인용 화면이 직접 계산하던 식을 풀어 보니 TWEEN 의 Quadratic.InOut 과 같은 식이었다
        - 방법이 다른 것과 결과가 다른 것은 별개다
    - 처리
        - 곡선 둘만 인자로 두면 되었다. Out 과 InOut 이다
        - **다르게 쓰여 있다고 다른 결과가 나오는 것이 아니다.** 식을 풀어 맞대어 본다

2. 확인용 화면이 왜 직접 계산했는지 이유가 없었다
    - 증상
        - 그 화면에서 TWEEN 이 안 도는 줄 알고 확인했는데, 화면이 tween 을 읽고 매 프레임 돌리고 있었다
    - 원인
        - 필요해서가 아니라 그냥 따로 만든 것이었다
    - 처리
        - 옮기고 나서 21줄이 3줄이 되었다
        - **따로 만든 것에 이유가 있는지 먼저 확인한다.** 이유가 없으면 그냥 모으면 된다
