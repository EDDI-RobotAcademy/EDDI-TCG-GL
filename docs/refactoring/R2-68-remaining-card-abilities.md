# [ETWGL-R2-68] 남은 카드 일곱을 전투 상태가 처리하게 한다

선행: R2-67 │ 후행: R2-69 │ 산출물: 카드 여덟을 전투가 처리한다 │ Type: Rule │ Domain: Battle Ability

# Success criteria

1. 왜 하는지와 어디까지 할지를 정한다
    - 문제
        - 카드 열둘 중 다섯만 전투가 처리한다. 일곱은 화면이 조립한다
        - 그래서 화면이 전투를 직접 고치는 곳이 스무 군데 남아 있다
        - 그것이 남아 있으면 [화면은 돌려받은 것만 보고 그린다] 로 갈 수 없다
    - 목적
        - 값으로 다 적히는 카드를 전투가 처리하게 한다
    - 기대 결과
        - 화면이 전투를 직접 고치는 곳이 크게 준다
    - 왜 이 자리로 당겼나
        - 원래 다음이 [화면이 돌려받은 것만 보고 그린다] 였다
        - 그런데 화면이 아직 전투를 직접 고치는 곳이 스무 군데다. 그것이 다 이 일곱 장의 것이다
    - 건드리지 않는 것
        - 값으로 안 되는 넷 - R2-58 에서 가려냈다. 한 번에 안 끝난다
        - 스킬 비용을 보는 곳 - 아직 화면이 본다

2. 카드에 붙은 에너지를 전투로 옮긴다
    - 종족마다 따로 세야 한다. 스킬 비용이 종족별로 정해져 있다
    - 앞으로 여러 종족을 함께 요구하는 스킬이 나오면 총량으로는 판정할 수 없다
    - 상대 유닛의 에너지도 같은 것이다. 세는 방식만 총량으로 쓴다

3. 사용자가 고르는 것을 어떻게 보낼지 정한다
    - 레오닉의 부름은 덱에서 무엇을 고를지를 사용자가 정한다
    - 고른 자리를 함께 보낸다. 빼고 넣고 섞는 것은 전투가 한다

4. 무작위를 어떻게 다룰지 정한다
    - 레오닉은 고르고 나면 덱을 섞는다
    - 씨앗은 밖에서 받는다. R2-51 에서 정한 그대로다

5. 게임 동작이 달라지지 않았는지 확인한다
    - 죽음의 에너지, 넘쳐 흐르는 사기, 레오닉의 부름

# Issue

1. 붙은 에너지를 총량 하나로 세고 있었다
    - 증상
        - R2-61 에서 상대 유닛의 에너지를 옮길 때 숫자 하나로 뒀다
        - 그런데 아군 유닛의 에너지는 종족마다 따로 세고 있었다
    - 원인
        - 상대 유닛은 에너지 번이 총량만 보므로 숫자 하나로 충분했다
        - 아군 유닛은 스킬 비용이 종족별이라 총량으로는 판정할 수 없다
    - 처리
        - 종족마다 세게 하고, 총량은 더해서 준다
        - **쓰는 쪽이 총량만 보더라도 담는 쪽은 갈라 둔다.** 나중에 가르는 것이 더 비싸다

2. 덱을 섞는 것이 연출 뒤에 있었다
    - 증상
        - 레오닉이 고르고 나면 덱을 섞는데, 그것이 연출이 다 끝난 뒤였다
    - 원인
        - 화면이 순서를 조립하다 보니 [다 끝나면 정리한다] 자리에 들어갔다
    - 처리
        - 고른 것을 빼고 손패에 넣고 섞는 것을 전투가 한 번에 한다
        - **한 사용자 행동이 만드는 일은 다 같은 자리에서 끝난다**

3. 옮기는 동안 값이 두 곳에 산다
    - 증상
        - 카드에 붙은 에너지를 전투와 화면 양쪽에 넣고 있다
    - 원인
        - 스킬 비용을 보는 쪽이 아직 화면 것을 읽는다. 한쪽만 채우면 스킬이 안 나간다
    - 처리
        - 옮기는 동안 양쪽을 채워 둔다. 스킬 비용을 옮길 때 화면 쪽을 지운다
        - **다 옮길 때까지 두 곳에 사는 값이 생긴다.** 언제 지울지를 함께 정해 둔다
