# Issue

1. 표의 한 줄이 사실과 달랐다
    - 증상
        - [화면 → 도메인 물건(집합체, 부품, **세션**)] 이 금지로 적혀 있는데, 화면은 세션을 들고 있다
    - 원인
        - 화면이 세션을 드는 것이 전투와 말하는 유일한 길이다. 금지일 수가 없다
        - 읽기 창구 항목의 [세션 내부는 넘기지 않는다] 와 섞여 [세션] 으로 줄여 적힌 것으로 보인다
    - 처리
        - [집합체, 부품] 으로 고치고, 화면이 드는 것은 세션이고 못 드는 것은 세션이 내주던 것임을 적었다
        - **검사를 붙이려고 표를 한 줄씩 읽다가 나왔다.** 표는 읽히지 않으면 틀린 채로 남는다

2. 두 줄은 새 검사가 필요 없었다
    - 증상
        - [화면이 상태를 고치면 안 된다] 에 검사를 붙이려다 이미 막혀 있음을 알았다
    - 원인
        - 고치려면 도메인 물건이 있어야 하고, 가지려면 들여와야 하고, 그건 `ui-no-domain-object` 가 잡는다
    - 처리
        - 검사를 더하지 않고 그 이름을 적었다
        - 다만 그것이 성립하는 조건 둘을 함께 적었다 — 읽기 창구가 평범한 값만 내놓고, 세션이 판을 안 내준다
        - **둘 중 하나라도 도메인 물건을 내놓기 시작하면 두 줄이 조용히 다시 사람 일이 된다.** 검사 이름만 적어 두면 그 사실이 안 보인다
