# [ETWGL-R2-70] 유닛이 움직일 수 있는지를 전투 상태가 판단한다

선행: R2-69 │ 후행: R2-71 │ 산출물: 유닛에 붙는 것 넷이 전투 안에 있다 │ Type: Rule │ Domain: Battle Unit

# Success criteria

1. 왜 하는지와 어디까지 할지를 정한다
    - 문제
        - 유닛이 이번 턴에 움직일 수 있는지를 화면이 판단한다
        - 나온 턴, 빙결, 재빙결 불가, 암흑 화염을 화면이 목록 넷으로 따로 든다
        - 그것들은 유닛에 붙어 있다가 나중에 일어나는 일을 바꾸는 것이다. 화면이 들 것이 아니다
    - 목적
        - 유닛으로 때릴 때 움직일 수 있는지를 전투가 판단하게 한다
    - 기대 결과
        - 화면은 때리라고만 하고, 안 되면 왜 안 되는지 돌려받는다
    - 건드리지 않는 것
        - 턴이 넘어갈 때 정산하는 일 - R2-71
        - 붙은 것을 화면에 그리는 것 - 화면이다

2. 유닛에 붙는 것을 찾는다
    - 나온 턴, 빙결, 재빙결 불가, 암흑 화염
    - 넷 다 유닛에 붙어 있다가 나중을 바꾼다

3. 움직일 수 있는지를 누가 판단할지 정한다
    - 나온 턴에는 못 움직인다. 나오자마자 때리는 것을 막는 규칙이다
    - 얼어 있으면 못 움직인다
    - 둘 다 전투가 본다. 안 되면 왜 안 되는지를 돌려준다

4. 재빙결 불가를 어떻게 다룰지 정한다
    - 화면은 얼린 것 목록과 면역 목록 둘을 들고 턴마다 서로 옮기고 있었다
    - 유닛이 스스로 알게 한다. 얼려 달라고 하면 면역인지 보고 얼거나 안 언다

5. 게임 동작이 달라지지 않았는지 확인한다
    - 소환 멀미, 암흑 화염, 빙결

# Issue

1. 제목이 무엇을 하는지 안 가리켰다
    - 증상
        - 이 티켓의 제목이 [화면 표시가 상태를 들고 있지 않게 한다] 였다
        - 무엇을 하는 이야기인지, 사용자가 무엇을 하는지가 안 보인다
    - 원인
        - 값이 어디 있느냐로 제목을 지었다
    - 처리
        - 사용자가 하는 일 둘로 갈랐다. 유닛으로 때린다, 턴을 끝낸다
        - **제목을 못 쓰면 티켓이 잘못 잡힌 것이다.** 규칙 19 에 붙였다

2. 목록 둘로 하던 것을 유닛이 스스로 알게 했다
    - 증상
        - 얼린 것 목록과 면역 목록이 따로 있었다. 턴마다 하나에서 다른 하나로 옮겼다
    - 원인
        - 유닛이 자기 상태를 안 들고 있어서 밖에서 목록으로 관리했다
    - 처리
        - 유닛이 얼었는지와 면역인지를 든다. 얼려 달라고 하면 스스로 보고 얼거나 안 언다
        - **목록 둘 사이를 오가는 값은 그 대상이 들 수 있다.** 오가는 것이 곧 상태가 바뀌는 것이다

3. 상태를 옮기면 읽는 쪽이 그 자리에서 끊긴다
    - 증상
        - 붙이는 쪽을 전투로 옮기니 암흑 화염 정산이 아무 일도 안 하게 됐다. 옛 목록이 늘 비어 있다
    - 원인
        - 붙이는 쪽과 읽는 쪽이 다른 함수에 있어서 한쪽만 옮겼다
    - 처리
        - 같은 티켓에서 읽는 쪽도 함께 옮겼다
        - **상태를 옮길 때는 그 상태를 읽는 곳을 다 세고 함께 옮긴다.** 안 그러면 조용히 안 돈다
