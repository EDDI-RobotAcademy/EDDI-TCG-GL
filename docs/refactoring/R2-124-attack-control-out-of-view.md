# Issue

1. 같아 보이는 코드 두 벌이 실은 달랐다
    - 증상
        - 붉게 번쩍이고 쓰러진 것을 감추는 코드가 광역기 쪽과 단일기 쪽에 두 벌 있었다
        - 한 벌로 합치려고 읽어 보니 둘이 다른 일을 하고 있었다
    - 원인
        - 광역기는 맞은 카드를 흔들고 단일기는 안 흔든다. 사라지기까지 기다리는 시간도 450 대 300 이다
        - 단일기는 때리는 카드가 날아와 부딪히는 움직임이 이미 충격을 말해 준다. 광역기는 그 움직임이 없다
    - 처리
        - 합치지 않았다. 다른 점 둘만 표로 두고 나머지는 함께 쓴다
        - **생김새가 같아 보여도 왜 그렇게 되어 있는지를 먼저 읽는다. 여기서 합쳤다면 단일기에 없던 흔들기가 생겼을 것이고, 사용자가 찾아 줄 종류의 변화였다**

2. 광선을 맞추는 일이 누름 처리기 맨 위에 한 번만 있었다
    - 증상
        - 눌린 것을 찾는 일을 셋으로 나눠 밖으로 넘기니 광선이 안 맞은 상태로 찾게 됐다
    - 원인
        - 원래는 처리기 맨 위에서 광선을 한 번 맞추고 아래 셋이 그것을 계속 썼다
        - 찾는 일만 넘기고 맞추는 일을 안 넘겼다
    - 처리
        - 맞추는 일도 넘기는 자리로 두고, 처리기 맨 위에서 한 번 부른다. 아래 셋은 전처럼 같은 광선을 쓴다
        - **[한 번 준비하고 여러 번 쓰는 것] 을 나눌 때는 준비하는 쪽도 함께 나눈다**

## 사용자가 하는 순서가 상태 넷이다

| 상태 | 사용자가 할 수 있는 것 |
| --- | --- |
| 아무것도 안 골랐다 | 내 유닛을 집는다 |
| 내 유닛을 집었다 | 오른쪽 단추로 패널을 연다 |
| 패널이 열려 있다 | 일반 공격이나 스킬을 고른다 |
| 단일기를 골랐다 | 상대 유닛이나 본체를 누른다 |

광역기는 고른 순간 바로 나간다. 대상을 고를 것이 없다.

## 합치지 않은 둘

| | 흔드나 | 사라지기까지 |
| --- | --- | --- |
| 광역기 | 흔든다 | 450ms |
| 단일기 | 안 흔든다 | 300ms |

단일기는 때리는 카드가 날아와 부딪히는 움직임이 이미 충격을 말해 준다. 광역기는 그 움직임이
없어 흔들어야 맞은 것이 보인다. 사라지기까지 기다리는 시간도 흔드는 쪽이 더 길다 — 흔들기가
끝나야 사라진다.

**표로 두었다.** 코드 두 벌은 한 벌이 됐고, 다른 점 둘은 표에 남았다.

## 카드 번호로 갈리던 한 갈래는 화면에 남겼다

네더 블레이드는 신화 등급에 맞는 광역기 연출을 아직 안 만들어서 스킬 자리로 나갔다 오기만
한다. 그 판단은 연출을 아는 화면 쪽에 두고, 때리기에는 **카드 번호가 하나도 없다.**

연출을 카드별로 나누는 것은 따로 세웠다 (R2-131). 카드가 내놓는 것에 [광역기 연출] 자리가
없어서, 그것을 더하는 일이 먼저다.

| 구분 | 내용 |
| --- | --- |
| **잘 맞은 것** | 상태 넷이 사용자가 하는 순서와 똑같아졌다. 읽으면 순서가 보인다. |
| **잘 맞은 것** | 두 벌인 코드를 합치려다 둘이 다름을 먼저 읽었다. 합쳤으면 사용자가 찾아 줄 변화였다. |

| **미흡한 것** | 기대는 것이 스물넷이다. 다섯 덩어리 중 가장 큰 것이라 그렇지만, 손패까지 옮긴 뒤 다시 봐야 한다. |
