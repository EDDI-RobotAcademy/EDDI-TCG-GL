# Issue

1. 아무것도 안 걸리는 규칙과 잘 도는 규칙이 겉으로 똑같다
    - 증상
        - 규칙 셋을 걸었더니 바로 통과했다
    - 원인
        - 검사는 걸리는 것이 없으면 통과한다. 규칙을 잘못 써서 아무것도 안 걸려도 똑같이 통과한다
        - 그러면 규칙이 있다고 믿으면서 실제로는 안 지켜진다
    - 처리
        - 셋을 일부러 넘는 파일을 만들어 넣고 셋 다 잡히는 것을 봤다. 확인하고 지웠다
        - **검사를 걸었으면 일부러 어겨 보고 잡히는지 본다. 통과는 증거가 아니다**

2. 아는 위반을 예외로 적으면 예외가 너무 넓어질 수 있다
    - 증상
        - 지금 넘는 곳이 파일 둘, 셋 군데다. 넘는 것을 막으면서 그 둘은 지나가게 해야 한다
    - 원인
        - 폴더째 예외로 두면 그 폴더에서 새로 넘는 것도 같이 지나간다
    - 처리
        - 파일 이름 두 개를 콕 집어 예외로 적었다
        - 예외를 뺐을 때 아는 셋만 잡히고 다른 것은 안 잡히는 것을 확인했다
        - 예외마다 어느 티켓이 고치는지 옆에 적었다
        - **예외는 폴더가 아니라 파일로 적는다. 고칠 티켓 번호를 옆에 적어 둔다**

3. 잴 수 있는 것과 없는 것을 가르지 않으면 표를 믿게 된다
    - 증상
        - 지침 표에 ✗ 가 열한 줄인데, 그중 기계가 재는 것은 넷이다
    - 원인
        - 표에 다 같은 ✗ 로 적혀 있어서 어느 것이 지켜지고 어느 것이 사람 몫인지 안 보인다
    - 처리
        - 표에 [무엇이 재어지는가] 칸을 붙였다. 빈 칸은 사람이 봐야 하는 것이다
        - **지켜지는 규칙과 적어만 둔 규칙을 같은 표에 같은 모양으로 적지 않는다**
