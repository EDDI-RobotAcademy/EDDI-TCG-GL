# Issue

1. 폴더를 통째로 지우니 안에 있던 것이 조용히 따라갔다
    - 증상
        - 지운 것을 보고할 때 화면 코드 줄 수만 셌다
        - 실제로는 자리 표시 파일 93개가 함께 지워졌다. 보고에 없었다
    - 원인
        - `git rm -r` 로 폴더를 통째로 지우고, 안에 무엇이 들었는지 안 봤다
    - 처리
        - 93개가 전부 지운 화면 셋 안의 것인지 확인했다. 밖으로 샌 것은 없다
        - 내용은 전부 한 줄이다. `resource/` 아래 그림과 소리는 git 에 안 올리기 때문에
          폴더 모양만 남기려고 넣어 둔 것이다. 화면이 없어졌으니 같이 없어지는 것이 맞다
        - **폴더를 통째로 지울 때는 안에 무엇이 딸려 가는지 보고 그것도 보고에 적는다**

2. 손댄 파일로 도메인을 골랐다
    - 증상
        - 처음에 Battle Unit 으로 넣었다
    - 원인
        - 고친 파일이 `card/unit/generate.ts` 였다
    - 처리
        - Battle Hand 로 고쳤다. 필드에 나온 뒤가 아니라 손패에서 내보내는 일이다
        - 같은 일을 다룬 R2-65, R2-76, R2-77, R2-78 이 이미 Battle Hand 다
        - **도메인은 어느 파일을 고쳤는지가 아니라 무엇에 대한 일인지로 정한다**
