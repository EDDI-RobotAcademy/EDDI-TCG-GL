# R2-84 사용하지 않는 손패 내보내기 방식 제거

| | |
|---|---|
| 갈래 | Structure |
| 도메인 | Battle Hand |
| 선행 | R2-54 |

## 왜 했는가

카드를 손패에서 끌어다 필드에 내보내는 방식이 두 개 있었다.

- 쓰는 쪽 — 사용자가 보는 전투 화면이 쓰는 방식
- 안 쓰는 쪽 — 확인용 화면 셋만 쓰던 방식

안 쓰는 쪽은 사용자가 보는 화면 어디에서도 부르지 않았다. 그런데 살아 있으니
손패에서 필드로 내보내는 일을 고칠 때마다 두 곳을 봐야 했다.

## 무엇을 했는가

안 쓰던 방식과, 그 방식에만 매달려 있던 확인용 화면 셋을 지웠다.

- 지운 확인용 화면 — 끌어다 놓기, 손패에서 필드로 내보내기, 제자리로 돌아가기
- 지운 코드 — 안 쓰던 내보내기를 맡던 파일 하나, 그리고 그 파일이 있어야만 돌던
  필드 카드 자리 맞추기 함수 하나

자리 맞추기 함수는 부르는 곳이 지운 확인용 화면 하나뿐이었다.

화면 폴더를 통째로 지웠기 때문에, 그 안에 있던 자리 표시 파일 93개도 함께
없어졌다. `resource/` 아래 그림과 소리 파일은 git 에 올리지 않기 때문에
폴더 모양만이라도 남겨 두려고 넣어 둔 것들이고, 내용은 전부 한 줄이다.
화면이 없어졌으니 그 자리 표시도 같이 없어지는 것이 맞다. 새로 만든
`draw_field_energy_full_efr` 에는 애초에 이런 파일이 없다.

## 지운 것을 무엇이 대신하는가

셋이 보여주던 것을 `draw-field-energy-full-efr` 한 화면이 다 보여준다.
그 화면은 사용자가 보는 전투 화면과 같은 길을 쓰기 때문에, 여기서 되면
사용자에게도 된다.

| 셋이 보던 것 | 지금 보는 곳 |
|---|---|
| 카드를 끌어다 놓기 | draw-field-energy-full-efr |
| 손패에서 필드로 내보내기 | draw-field-energy-full-efr |
| 필드를 벗어나면 제자리로 | draw-field-energy-full-efr |

- 확인 필요 — 손패에서 카드 끌기, 필드에 놓기, 필드 밖에 놓아 제자리로 돌아가기
