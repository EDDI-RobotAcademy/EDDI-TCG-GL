# Issue

1. 전투 화면이 자기 그림판을 안 감췄다
    - 증상
        - 테스트 전투를 먼저 들어간 뒤 상점이나 보유 카드로 가면 전투 화면이 그대로 보였다
        - 상점을 먼저 들어가면 안 그랬다. 사용자가 찾아 줬다
    - 원인
        - 다른 화면 셋은 자기 그림판과 함께 쓰는 자리를 둘 다 감춘다
        - 전투 화면은 함께 쓰는 자리만 감췄다. 다음 화면이 그 자리를 다시 보이게 하면 전투 그림판이 그 위에 남는다
    - 처리
        - 자기 그림판도 감추게 했다
        - **혼자 도는 화면을 여럿이 오가는 화면으로 옮길 때, 감추는 길을 새로 내야 한다.** 혼자 돌 때는 감출 일이 없어서 그 길이 없다

2. 설정에 있어야 할 것이 넷이나 빠져 있었다
    - 증상
        - 진입점을 고치니 그림을 못 찾고, 고치니 소리를 못 찾았다
    - 원인
        - 이 설정이 오래 안 돌아서 그 사이에 늘어난 것들이 안 들어갔다
        - 확인용 화면 설정에는 다 있다
    - 처리
        - 확인용 화면 설정과 나란히 놓고 없는 것을 가져왔다
        - **안 도는 설정은 그 사이에 늘어난 것을 못 따라간다.** 돌려 보는 것이 유일한 확인이다

3. 지켜볼 자리를 저장소 전체로 잡았다
    - 증상
        - 가만히 둬도 로비가 되풀이해 다시 떴다. 사용자가 찾아 줬다
    - 원인
        - 개발용 서버가 파일이 바뀌는지 지켜보다 바뀌면 화면을 다시 띄운다
        - 지켜볼 자리를 저장소 전체로 잡았다. 8.9 GB 다. 그 안의 무엇이 바뀌든 다시 뜬다
        - 확인용 화면은 자기 폴더만 지켜본다
    - 처리
        - 지켜보지 않게 했다. index.html 과 그림은 실행 중에 안 바뀐다
        - 같은 모양이 확인용 화면 여섯에 더 있어 함께 고쳤다
        - **지켜보는 자리는 바뀔 것만 담는다.** 넓게 잡으면 안 바뀌어야 할 것까지 지켜본다

4. 사용자에게 내보내는 명령이 없다
    - 증상
        - 다시 뜨는 것이 사용자에게도 일어나는지 물었는데, 사용자에게 줄 것을 만드는 명령이 아예 없었다
    - 원인
        - 지금까지 확인용 화면으로만 돌려 봐서 내보낼 일이 없었다
    - 처리
        - 이번 범위 밖이라 티켓으로 올렸다. R2-88
        - **개발용으로만 돌려 온 것은 내보내는 길이 없다.** 있는지 확인한다
