# Issue

1. 안 다시 재는 것이 다 같은 문제가 아니다
    - 증상
        - 티켓은 [다시 안 재는 화면 조각을 잇는다] 였다. 이으면 되는 것처럼 읽힌다
        - 열어 보니 열하나 중 넷만 이으면 되는 것이었다
    - 원인
        - [안 불린다] 로만 셌다. 왜 안 불리는지는 안 봤다
    - 처리
        - 넷으로 갈랐다. 다시 재는 방법을 안 부르는 것, 다시 만드는 길을 안 부르는 것,
          다시 만들 자리가 없는 것, 화면이 렌더러 것을 손으로 하는 것
        - 앞의 둘은 잇는 일이라 이 티켓에서 했다. 뒤의 둘은 동작을 바꾸는 판단과 되찾는 일이다
        - **안 되는 것을 셀 때는 왜 안 되는지까지 세어야 한 티켓인지 알 수 있다**

2. 렌더러에 다시 재는 방법이 없다고 없는 것이 아니다
    - 증상
        - 팝업 다섯을 [다시 재는 방법 자체가 없다. 만드는 일이다] 로 보고 범위 밖에 뒀다
        - 사용자가 작은 창에서 무덤을 열고 창을 키웠더니 작은 채로 남았다
    - 원인
        - 렌더러에 `resize` 가 있는지만 봤다. 팝업은 페이지를 넘길 때 통째로 다시 만드는데,
          그 길이 이미 다섯 다 있었다. 다시 재는 대신 다시 만들면 되는 것이었다
    - 처리
        - 다섯을 이었다. 만드는 일이 아니라 잇는 일이었으므로 이 티켓 안에서 했다
        - **어떻게 다시 그리는지는 렌더러만 보지 말고 화면이 이미 쓰는 길도 본다**

3. 창을 끌어서 바꾸면 팝업이 겹쳐 쌓인다
    - 증상
        - 다시 만들기를 그대로 이었더니, 창을 끌 때 이 일이 수십 번 불린다
        - 다시 만드는 것은 그림을 읽는 일이라 시간이 걸린다. 앞의 것이 끝나기 전에 다음 것이
          들어오면 앞의 것이 만든 팝업이 화면에 남은 채 새 팝업이 또 올라온다
    - 원인
        - 열려 있는지 보는 것과 실제로 만드는 것 사이에 기다리는 시간이 있다
    - 처리
        - 끌기가 멈춘 뒤에 한 번만 만들고, 만드는 중에 또 바뀌면 끝난 뒤에 한 번 더 만든다
        - **다시 그리는 일에 기다림이 있으면 창 끌기에 그대로 이으면 안 된다**

4. 다시 만들어도 아랫줄이 안 보인다
    - 증상
        - 팝업을 다시 만들게 했는데도 창을 낮추면 카드 윗줄만 보인다
    - 원인
        - 카드 크기는 창 너비만 보고 정해지고, 팝업 상자 높이는 창 높이로 정해진다
        - 창이 낮아지면 상자만 줄고 카드는 그대로라 두 줄이 안 들어간다. 들어갈 자리가
          없는 줄은 아예 안 만들어지므로 아랫줄이 통째로 사라진다
        - 간격은 카드 크기의 비율이라 카드를 따라 줄어든다. 간격 탓이 아니었다
    - 처리
        - 상자에 안 들어갈 때만 카드를 줄인다. 보통 크기에서는 하나도 안 바뀐다
        - 카드 안의 것이 전부 카드 가운데를 기준으로 놓이므로 통째로 줄여도 안 어긋난다
        - **가로로 재는 것과 세로로 재는 것이 한 상자에서 만나면 한쪽 창만 줄여 본다**

5. 그림이 안 따라가는 것은 눈에 잘 안 띈다
    - 증상
        - 창을 줄여도 무덤은 눌린다. 안내 문구도 뜬다. 얼핏 멀쩡해 보인다
    - 원인
        - 누르는 자리는 그때그때 창 크기로 다시 재고, 그림만 처음 크기에 남는다
        - 둘이 따로 놀아도 겹치는 데가 남아 있으면 눌리기는 한다
    - 처리
        - 그림 쪽을 창 크기에 맞췄다
        - **누르는 자리와 그림이 서로 다른 데서 크기를 가져오면 한쪽만 고쳐도 안 드러난다**
