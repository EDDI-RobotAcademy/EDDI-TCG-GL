# Issue

1. 같은 일처럼 보이는 둘이 한 줄 달랐다
    - 증상
        - 화면이 하는 것과 렌더러가 하는 것이 거의 같아서 그냥 바꿔 끼우면 될 것 같았다
    - 원인
        - 렌더러는 카드가 [나온 차례] 로 자리를 잡고, 화면은 [지금 필드에 남아 있는 차례] 로 잡는다
        - 가운데 것이 죽으면 뒤의 것이 한 칸 당겨 서야 하는데, 렌더러는 그것을 모른다
    - 처리
        - 그냥 바꿔 끼웠으면 죽은 카드가 다시 나타나고 산 카드가 빈 자리에 섰다
        - 살아 있는 카드의 번호를 순서대로 렌더러에 준다. 어느 자리에 서는지는 렌더러가 정한다
        - **바꿔 끼우기 전에 두 쪽이 같은 것을 세고 있는지 본다**

2. 같은 것을 또 만들 뻔했다
    - 증상
        - 살아 있는 카드 번호를 순서대로 주는 것을 새로 만들었는데, 이미 있었다
    - 원인
        - 쓰러진 유닛을 세는 다른 자리에서 쓰던 것이라 이름이 달라 눈에 안 띄었다
    - 처리
        - 새로 만든 것을 지우고 원래 있던 것을 썼다. 원래 것에 이 일에도 쓴다고 적어 뒀다
        - **필요한 것을 만들기 전에 같은 값을 이미 세는 곳이 있는지 본다**

3. 크기 다시 재기와 자리 다시 잡기는 함께 안 다닌다
    - 증상
        - 하나로 만들면 쓰러진 뒤 다시 세울 때마다 카드 크기까지 다시 재게 된다
    - 원인
        - 다시 세우는 일은 열 곳에서 부르는데 그중 창 크기가 바뀐 것은 한 곳뿐이다
    - 처리
        - 둘로 나눴다. 자리만 잡는 것과, 크기를 다시 잰 다음 자리를 잡는 것
        - 자리 잡는 규칙은 한 곳에만 있다. 크기 다시 재기가 그것을 부른다
        - **함께 부르는 곳이 열에 하나뿐이면 하나로 묶지 않는다**
