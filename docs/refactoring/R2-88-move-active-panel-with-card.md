# [ETWGL-R2-88] 창 크기 변경 시 액티브 패널을 카드 따라 옮기기

선행: R2-86 │ 후행: R2-89 │ 산출물: 액티브 패널 다시 재기 │ Type: Rendering │ Domain: Battle 공용

# Success criteria

1. 왜 하는지와 어디까지 할지를 정한다
    - 문제
        - 액티브 패널은 우클릭한 자리에 뜬다. 그 자리는 그때 카드가 있던 자리다
        - 창 크기가 바뀌면 카드는 새 자리로 가는데 패널은 누른 자리에 그대로 남는다
        - 어느 카드의 패널인지 알 수 없게 되고, 버튼 크기도 처음 크기에 남는다
    - 목적
        - 창 크기가 바뀌어도 패널이 그 카드에 대해 같은 자리에 서게 한다
    - 기대 결과
        - 패널을 열어 둔 채 창을 바꿔도 어느 카드 것인지 그대로 보인다
    - 건드리지 않는 것
        - 패널을 여닫는 조건 - 창 크기 때문에 닫지 않는다

2. 닫을지 옮길지 정한다

3. 패널이 어느 카드 것인지 화면이 알고 있는지 본다

4. 다시 만들지 고쳐 쓸지 정한다

5. 게임 동작이 달라지지 않았는지 확인한다

# Issue

1. 누른 자리를 그대로 기억하면 못 쓴다
    - 증상
        - 패널이 뜬 자리를 그대로 적어 두고 다시 쓰면, 창이 바뀔 때 패널만 제자리에 남는다
    - 원인
        - 누른 자리는 창 크기가 그때 얼마였는지에 딸린 값이다
    - 처리
        - 자리 대신 [그 카드의 가운데에서 얼마나 떨어져 있는가] 를 카드 크기에 대한 비율로 적었다
        - 창이 커지면 카드도 커지고 패널도 그만큼 떨어져 선다
        - **다음에도 쓸 자리는 창 기준이 아니라 무엇에 붙어 있는지로 적는다**

2. 다시 만들면 누르던 중에 놓친다
    - 증상
        - 팝업처럼 통째로 다시 만들려 했다
    - 원인
        - 패널의 버튼은 누를 수 있는 것이라, 다시 만들면 누를 것이 통째로 바뀐다
        - 창을 끌면서 누르면 방금 만든 것이 또 없어져 눌리지 않는다
    - 처리
        - 그림은 그대로 두고 크기와 자리만 고쳤다. 누를 것이 안 바뀌므로 끌면서 눌러도 된다
        - 팝업과 달리 기다리는 일이 없어 겹쳐 쌓일 일도 없다
        - **누를 수 있는 것은 다시 만들지 말고 고쳐 쓴다**

3. 카드보다 먼저 옮기면 한 발 늦게 따라온다
    - 증상
        - 패널 옮기기를 창 크기 다루는 자리 앞쪽에 두면 패널이 카드의 옛 자리를 따라간다
    - 원인
        - 카드가 새 자리로 가는 것은 손패와 상대 필드를 다시 세울 때다. 그보다 먼저 재면 옛 자리다
    - 처리
        - 맨 마지막으로 옮겼다
        - **무엇을 따라가는 것은 따라갈 것이 자리를 잡은 뒤에 잰다**
