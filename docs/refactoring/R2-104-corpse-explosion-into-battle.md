# [ETWGL-R2-104] 시체 폭발을 전투 상태가 처리한다

선행: R2-103 │ 후행: R2-105 │ 산출물: 시체 폭발의 전투 처리 │ Type: Rule │ Domain: Battle Ability

# Success criteria

1. 왜 하는지와 어디까지 할지를 정한다
    - 문제
        - 시체 폭발은 전투가 안 다룬다. 화면이 제물을 무덤으로 보내고 적을 때린다
        - R2-103 에서 기다리는 고르기를 만들었다. 이 카드가 그 바탕의 첫 손님이다
    - 목적
        - 제물 받기, 적 고르기, 때리기를 전투가 하고 화면은 그린다
    - 기대 결과
        - 고르기 바탕이 쓸 만한지 이 카드로 드러난다
    - 건드리지 않는 것
        - 피해량 규칙 - 카드 설명과 다른데 지금 동작 그대로 옮긴다. 옮긴 뒤에 따로 본다
        - 시체가 날아가고 터지는 그림 - 무엇을 보고 그리는지만 바꾼다

2. 화면이 지금 무엇을 하는지 본다

3. 카드 설명과 구현이 같은지 본다

4. 옮기고, 화면은 일어난 일로 그리게 한다

5. 게임 동작이 달라지지 않았는지 확인한다
    - 제물 고르기, 적 둘 고르기, 같은 적 두 번, 본체 고르기, 고르다 턴 종료

# Issue

1. 카드 설명과 구현이 달랐다
    - 증상
        - 카드 설명은 [제물의 현재 체력만큼] 인데 구현은 카드에 적어 둔 고정값을 쓴다
    - 원인
        - R2-85 에서 이 카드를 판정할 때 [고르기가 두 단계다] 만 보고 피해량은 안 봤다
    - 처리
        - 지금 동작 그대로 옮겼다. 옮기는 일과 규칙을 고치는 일은 다른 일이다 (규칙 3)
        - 섞으면 나중에 뭔가 깨졌을 때 옮겨서인지 규칙을 바꿔서인지 모른다
        - 뒤에 확인해 보니 **고정값 쪽이 정해진 규칙이고 카드 설명이 낡은 것** 이었다.
          고칠 일이 아니라 적어 둘 일이었다. 능력 값과 처리하는 자리 양쪽에 적었다
        - **옮기기 전에 카드 설명과 구현이 같은지 본다. 다르면 옮기는 일에 섞지 않는다**

2. 제물이 전투의 필드에 남아 있었다
    - 증상
        - 전에는 화면의 목록에서만 뺐다. 전투의 필드에서는 안 뺐다
    - 원인
        - 화면이 제 목록으로 필드를 그리니 눈에는 사라졌다. 전투 쪽은 아무도 안 봤다
    - 처리
        - 옮기면서 전투가 필드에서도 빼게 했다. 무덤으로 보내는 것과 한 자리에서 한다
        - **화면에서 사라졌다고 전투에서도 빠진 것은 아니다. 눈으로 확인되는 것만 보면 놓친다**

3. 발이 닿을 때마다 때리던 것을 한 번에 때리게 했다
    - 증상
        - 전에는 발이 하나 닿을 때마다 그 발의 피해를 줬다
    - 원인
        - 화면이 때렸으니 연출 박자에 맞춰 때릴 수 있었다
    - 처리
        - 전투는 다 골랐을 때 한 번에 때린다. 화면은 발이 닿을 때마다 그 결과를 그린다
        - 이미 서 있던 규칙 그대로다. 상태는 연출을 기다리기 전에 다 바꾼다
        - **연출 박자에 맞춰 값을 바꾸면, 연출이 끊겼을 때 반만 바뀐 상태가 남는다**
