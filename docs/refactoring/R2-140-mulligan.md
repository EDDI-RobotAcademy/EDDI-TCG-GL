## 사용자가 하는 순서

```
받은 다섯 장이 가운데 크게 뜬다
  ↓  바꾸고 싶은 카드를 누른다     네온 테두리가 붙고 카드가 가라앉는다
  ↓  [바꾸기 3]                    고른 세 장만 새로 온다
  ↓  [시작]                        겹이 걷히고 판이 차려진다
```

| | 정한 것 | 왜 |
| --- | --- | --- |

| 꽂는 자리 | **있던 자리 그대로** | 자리가 흐트러지면 무엇이 바뀌었는지 못 본다 |

테두리만으로는 [고름] 인지 [강조] 인지 헷갈려서, 고른 카드는 **가라앉히고** 오른쪽 위에
**↻ 표**를 붙였다. 테두리가 밝기를 오르내리는 한 바퀴는 1.1초다 — 초에 한 번보다 빠르면
눈이 아프다.

## 순서를 바꾼 이유

```
전에 하려던 것:  판을 차린다 → 겹을 띄운다 → 바꾼다 → 전투 상태를 다시 손본다   ✗
지금:           겹을 띄운다 → 바꾼다 → **바뀐 손패로** 판을 차린다              ⭕
```

판을 먼저 차리면 바뀐 카드를 넣으려고 전투 상태를 고쳐야 한다. **그건 화면이 할 일이
아니다.** 겹에서 기다렸다가 한 번에 차린다.

무엇으로 바뀌는지도 겹이 정하지 않는다. 고른 **자리**만 넘기고 바뀐 다섯 장을 받는다 —
덱에 돌려 넣고 섞고 다시 뽑는 것은 판 차리는 쪽 일이고, 서버가 붙으면 서버 일이다.
