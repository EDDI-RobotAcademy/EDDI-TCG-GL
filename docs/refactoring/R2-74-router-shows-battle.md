# [ETWGL-R2-74] 로비에서 들어간 전투 화면이 실제 전투를 띄우게 한다

선행: R2-29 │ 후행: R2-75 │ 산출물: 라우터가 BattleFieldView 를 띄운다 │ Type: Rendering │ Domain: Battle

# Success criteria

1. 왜 하는지와 어디까지 할지를 정한다
    - 문제
        - 로비에서 전투 화면으로 들어가면 배경만 나온다. 유닛도 손패도 없다
        - 실제 전투를 조립하는 화면은 따로 있는데 확인용 화면에서만 돈다
        - 사용자가 로비를 거쳐 도달할 수 있는 전투가 없다
    - 목적
        - 로비에서 들어간 화면이 실제 전투를 띄우게 한다
    - 기대 결과
        - 로비 → 전투 → 로비 로 오갈 수 있다
    - 건드리지 않는 것
        - 전투 화면이 무엇을 그리는지 - 이미 만들어져 있다
        - 확인용 화면 - 그대로 둔다

2. 실제 전투 화면이 라우터에 걸릴 수 있는지 본다
    - 라우터는 넷을 요구한다. 준비, 보이기, 감추기, 그리기
    - 그리기가 없다. 이 화면은 애니메이션을 스스로 돌려서 그 길을 안 냈다

3. 배경만 그리던 화면의 처지를 정한다
    - 라우터에서 떼면 아무도 안 쓴다
    - 규칙 17 대로 셋 다 세고 지운다

4. 로비를 거쳐 오갈 수 있는지 본다
    - 들어가고, 뒤로 가고, 다시 들어간다

5. 게임 동작이 달라지지 않았는지 확인한다
    - 본편 전투 화면, 뒤로 가기

# Issue

1. 라우터가 요구하는 것 하나가 빠져 있었다
    - 증상
        - 실제 전투 화면을 라우터에 걸 수 없었다. 그리기 길이 없다
    - 원인
        - 이 화면은 애니메이션을 스스로 돌린다. 밖에서 시킬 일이 없어서 안 냈다
    - 처리
        - 이미 돌고 있으면 아무 일도 안 하고, 멈춰 있으면 다시 돌리게 했다
        - **스스로 하는 것이라도 밖에서 부를 길은 낸다.** 안 내면 그 자리에 못 건다

2. 배경만 그리는 화면이 라우터에 걸려 있었다
    - 증상
        - 로비에서 전투로 들어가면 배경만 나온다
        - 실제 전투를 조립하는 화면은 확인용 화면에서만 돈다
    - 원인
        - 전투를 만들면서 새 화면을 따로 만들었는데 라우터는 옛것을 그대로 가리켰다
    - 처리
        - 라우터를 새것으로 바꾸고 옛것을 지웠다
        - **화면을 새로 만들 때 그것을 가리키는 곳도 함께 옮긴다.** 안 옮기면 만든 것이 안 보인다

3. 순환 경고가 하나 줄었다
    - 증상
        - 옛 화면을 지우니 의존 검사의 순환 경고가 여섯에서 다섯이 됐다
    - 원인
        - 그 화면이 라우터를 들고, 라우터가 그 화면을 들었다
    - 처리
        - 새 화면은 라우터를 안 든다. 화면을 옮기는 일이 없어서다
        - **화면이 라우터를 들면 순환이 생긴다.** 화면을 옮길 일이 없으면 안 든다
