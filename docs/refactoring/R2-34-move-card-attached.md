    - 기대 결과
        - 손패든 필드든 카드에 붙는 것을 고칠 때 battle/card/ 를 본다
        - 표시 종류를 하나 늘릴 때 한 곳만 고친다
    - 옮기기 전에 확인한 것
        - 다섯 다 손패와 필드 양쪽이 쓴다. 어느 한쪽 아래로 넣으면 반대쪽이 남의 폴더를 부르게 된다
        - 표시 종류 두 벌은 값이 같고 쉼표 하나만 달랐다
    - 옮기는 것
        - 17파일
    - 건드리지 않는 것

        - 이름을 Cache, Store 로 바꾸는 일 - 자리가 잡혔으니 다음에 한다. R2-36

2. 어디에 둘지 정한다

    - battle/hand/, battle/field/ 와 나란히 놓인다

4. 두 벌인 표시 종류를 한 벌로 만든다
    - 필드에 나온 카드에는 내 것이든 상대 것이든 같은 표시가 붙는다. 종족, 무기, 체력, 에너지가 양쪽 다 보인다
    - 한쪽에만 생길 표시가 보이지 않는다. 그래서 합친다
    - 남기는 쪽에 왜 한 벌인지 적어 둔다

    - 상대 필드 카드의 표시
    - 카드 상세 보기, 네온 테두리, 키보드 조작

# Issue

1. 값이 같은 두 벌이 쉼표 하나만 달랐다
    - 증상
        - 표시 종류 열거형이 내 쪽과 상대 쪽에 있었다. 값은 일곱 개로 같고 마지막 줄 쉼표만 달랐다
    - 원인
        - 상대 쪽을 만들 때 내 쪽을 베꼈다
    - 처리
        - 한 벌로 만들고 열 곳이 그것을 보게 했다
        - 남긴 파일 첫머리에 왜 한 벌인지와 예전에 두 벌이었다는 것을 적었다
        - **베낀 것은 값이 같아도 따로 자란다.** 쉼표 하나 차이가 그 증거다

2. 옮긴 뒤에야 합칠 자리가 정해졌다
    - 증상
        - R2-33 에서 두 벌인 것을 찾았지만 합치지 못하고 넘겼다
    - 원인
        - 그때는 내 쪽이 아직 최상위에 있어서, 합치면 상대 쪽이 최상위 폴더를 부르게 됐다
        - 이번에 내 쪽이 battle/card/ 로 들어오면서 양쪽이 함께 부를 자리가 생겼다
    - 처리
        - 옮기고 나서 합쳤다
        - **합칠 자리가 없으면 합치지 않는다.** 옮기는 것이 먼저다
