# Issue

1. 연출을 위층으로 올렸다가 그림이 달라졌다
    - 증상
        - 투명한 캔버스를 화면 위에 얹고 연출을 그쪽에 그렸더니 전혀 다른 그림이 됐다
    - 원인
        - 균열, 충격파 고리, 섬광 셋이 밑에 이미 그려진 색에 더해서 빛나는 방식이다. 빈 층에는 더할 것이 없어 빛이 죽는다
        - 어둠막은 밑에 깔린 것을 어둡게 하는 것이다. 위층에 올리면 게임 화면이 아니라 화면 위 정보까지 어두워진다
        - 재질 여덟 개가 색과 투명도를 따로 낸다. 새로 만든 층은 [색에 투명도가 이미 곱해져 있다] 로 잡혀 있어 색이 틀어진다
    - 처리
        - 연출을 옮기는 방향을 접고 패널을 캔버스로 내렸다
        - **밑에 무엇이 그려져 있는지에 기대는 연출은 층을 옮길 수 없다.** 옮기기 전에 재질이 무엇에 기대는지 본다

2. 뒤로 내리려고 준 값이 통하지 않았다
    - 증상
        - 패널을 잠깐 뒤로 내리려고 zIndex 를 0 으로 줬는데 아무것도 달라지지 않았다
    - 원인
        - 패널은 자리를 지정한 요소이고 캔버스는 아니다. 브라우저는 자리를 지정한 요소를 항상 위에 그린다. 0 으로는 안 내려간다
    - 처리
        - 이 방향 자체를 접었지만 값은 확인했다. 음수여야 내려간다
        - **0 은 [맨 아래] 가 아니다**

3. 글자 자리 기준을 잘못 잡았다
    - 증상
        - 숫자가 원래보다 아래에 찍혔다
    - 원인
        - 원래 계산은 글자 크기의 0.1 만큼 내리는 것인데, 패널 높이의 0.1 로 잡았다
    - 처리
        - 글자 크기 기준으로 고쳤다
        - **옮겨 그릴 때는 원래 계산식을 그대로 옮긴다.** 비슷한 이름의 값이 여럿이다

4. 화면 문제를 세 번 추측으로 고쳤다
    - 증상
        - 층을 옮겼다가 되돌리고, 값을 내렸다가 되돌리고, 다시 층을 옮겼다. 그동안 화면을 세 번 확인하게 했다
    - 원인
        - 무엇이 어느 층에 있는지 세지 않고 짐작으로 고쳤다
    - 처리
        - **화면이 가려지는 문제는 무엇이 어느 층에 있는지부터 센다.** 캔버스 안인지 위에 얹힌 조각인지, 자리를 지정했는지, 그리는 순서가 몇인지
