# Issue

1. 경로를 고치는 정규식이 이미 맞던 것까지 건드렸다
    - 증상
        - 옮긴 뒤 타입 오류 3건이 났다. battle/ability/entity 를 못 찾았다
    - 원인
        - 밖으로 나가는 ../../ 를 ../../../ 로 바꾸는 정규식을 걸었는데, 이미 battle 안을 가리키던 ../../ability/ 까지 바뀌었다
        - 옮긴 폴더 안에 이전 작업에서 정리된 경로가 이미 있다는 것을 생각하지 못했다
    - 처리
        - battle 내부를 가리키던 셋을 원복했다
        - **여러 번에 걸쳐 옮기는 폴더는 이미 고쳐진 경로가 섞여 있다.** 일괄 치환 전에 대상이 무엇인지 확인한다

2. 나갔다 들어오는 경로가 생겼다
    - 증상
        - from "../../../battle/active_panel/SkillPanelAnimator" 처럼 자기 폴더를 밖으로 나갔다 다시 들어오는 경로가 6파일에 생겼다
    - 원인
        - active_panel_area/ 를 battle/active_panel/ 로 바꾸는 치환을, 이미 battle 안에 있는 파일에도 적용했다
    - 처리
        - 상대 경로를 다시 계산해 ../SkillPanelAnimator 로 줄였다
        - **타입 검사는 경로가 추한 것을 잡아주지 않는다.** 통과했다고 끝난 것이 아니다
        - 옮긴 뒤 나갔다 들어오는 경로가 있는지 따로 본다
