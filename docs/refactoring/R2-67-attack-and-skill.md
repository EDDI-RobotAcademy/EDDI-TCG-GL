# [ETWGL-R2-67] 공격과 스킬을 전투 상태가 처리한다

선행: R2-66 │ 후행: R2-68 │ 산출물: 공격 넷을 전투가 처리한다 │ Type: Rule │ Domain: Battle Unit

# Success criteria

1. 왜 하는지와 어디까지 할지를 정한다
    - 문제
        - 공격할 때 화면이 다섯에서 여섯 줄을 순서대로 부른다
        - 체력을 깎고, 죽었는지 보고, 무덤에 넣고, 필드에서 빼는 것을 화면이 조립한다
        - 게다가 연출을 기다린 뒤에 값을 바꾼다. 기다리는 동안 화면이 닫히면 어중간해진다
    - 목적
        - 때리는 일 하나를 전투가 받아 끝까지 처리하고, 무슨 일이 있었는지 돌려주게 한다
    - 기대 결과
        - 화면은 하나만 보내고 돌려받은 것으로 연출을 튼다
    - 건드리지 않는 것
        - 얼마나 때리는지 - 무기 힘과 스킬 값을 읽는 길이 아직 카드 정보 쪽에 있다
        - 누구를 고를 수 있는지 - 화면이 눌러서 고른다

2. 때리는 방식을 넷으로 나눈다
    - 상대 유닛 하나, 상대 본체
    - 상대 유닛 전부, 상대 유닛 전부와 본체
    - 뒤의 둘은 스킬이 어디까지 가느냐로 갈린다

3. 값을 연출 앞으로 옮긴다
    - 공격 셋 다 연출을 기다린 뒤에 값을 바꾸고 있었다
    - R2-62 에서 카드 효과에만 적용한 규칙이다. 공격 쪽은 그때 못 봤다

4. 화면에 무엇을 남길지 정한다
    - 연출을 트는 일, 번쩍이고 흔드는 일, 쓰러진 것을 감추는 일
    - 맞고도 살아 있을 때만 붙는 것 — 암흑 화염과 빙결. 전투가 돌려준 값으로 판단한다

5. 게임 동작이 달라지지 않았는지 확인한다
    - 일반 공격, 광역기, 암흑 화염

# Issue

1. 같은 잘못이 다른 자리에 또 있었다
    - 증상
        - 공격 셋이 연출을 기다린 뒤에 값을 바꾸고 있었다
    - 원인
        - R2-62 에서 카드 효과 함수만 훑었다. 공격은 효과 함수가 아니라 누름 감지 안에 있었다
    - 처리
        - 셋 다 값을 연출 앞으로 옮겼다
        - **같은 잘못을 고칠 때는 그 모양이 있는 곳을 다 센다.** 한 종류만 훑으면 다른 종류에 남는다

2. 얼마나 때리는지는 아직 밖에서 온다
    - 증상
        - 전투가 [이만큼 때려라] 를 받는다. 얼마인지는 전투가 안 정한다
    - 원인
        - 무기 힘과 스킬 값을 읽는 길이 카드 정보 쪽에 있고, 화면이 그것을 읽어 쓴다
    - 처리
        - 이번에는 받아서 쓰기로 했다. 그 길을 전투로 내는 것은 카드 정보를 어디까지 전투가 알지를 정한 뒤다
        - **한 번에 다 안으로 들이면 전투가 카드 백 장을 알게 된다.** 무엇까지 알지를 먼저 정한다

3. 광역기가 목록을 돌면서 그 목록을 줄인다
    - 증상
        - 상대 유닛 전부를 때리는데, 쓰러지면 그 목록에서 빠진다
    - 원인
        - 도는 중에 빠지면 뒤엣것을 건너뛴다
    - 처리
        - 미리 베껴 두고 돌게 했다. 파멸의 계약에서 한 것과 같다
        - **도는 중에 줄어드는 목록은 미리 베껴 둔다**
