# Issue

1. 옮기려는 규칙 하나에 옮기면 안 되는 것이 붙어 있었다
    - 증상
        - 암흑 화염 정산은 유닛을 깎는다. 깎으면 쓰러질 수 있고, 쓰러지면 무덤으로 간다
    - 원인
        - 쓰러뜨리기와 무덤으로 보내기는 암흑 화염만의 일이 아니다. 맞는 모든 경우에 같다
        - 통째로 옮기면 그 공통 부분이 상태 규칙 쪽으로 딸려 간다
    - 처리
        - 상태 규칙은 [누가 얼마 맞는가] 만 낸다. 깎는 것은 카드 처리에 남겼다
        - **옮길 것에 공통인 부분이 붙어 있으면, 붙은 데서 자르고 공통인 쪽을 남긴다**

2. 어디까지가 상태 규칙인지 선이 애매한 자리가 둘 있었다
    - 증상
        - [차갑게 불타는 암흑 에너지를 쓰면 표시가 붙는다] 와 [얼어 있으면 못 움직인다]
    - 원인
        - 둘 다 상태를 건드리긴 한다
    - 처리
        - 앞의 것은 남겼다. **어느 카드** 를 썼는지를 보므로 카드 처리다
        - 뒤의 것도 남겼다. 표시 하나를 읽어 답하는 것이지 훑으며 바꾸는 것이 아니다
        - **[카드를 보는가] 와 [훑으며 바꾸는가] 로 갈랐다. 상태를 건드린다고 다 옮기지 않는다**

3. 옮기고 나서 부르는 쪽이 길어졌다
    - 증상
        - 전에는 번호 둘만 넘기면 됐는데 이제 유닛 둘을 찾아서 넘긴다
    - 원인
        - 상태 규칙이 전투 전체를 안 받게 했다. 유닛만 받는다
    - 처리
        - 그대로 뒀다. 규칙이 전투 전체를 받으면 무엇이든 꺼내 쓸 수 있게 되고, 그러면 옮긴 뜻이 없다
        - **부르는 쪽이 조금 길어지는 것과, 규칙이 전부를 볼 수 있게 되는 것 중 앞을 택한다**

| 남긴 것 | 왜 |

가른 선은 **[카드를 보는가]** 와 **[훑으며 바꾸는가]** 다. 상태를 건드린다고 다 옮기면
카드 처리가 텅 비고 상태 규칙이 다시 한 덩어리가 된다.

## 깎는 일을 안 옮긴 이유

암흑 화염 정산은 유닛을 깎는다. 깎으면 쓰러질 수 있고 쓰러지면 무덤으로 간다.

```
암흑 화염 정산
  ├ 누가 얼마 맞는가        ← 상태 규칙으로 옮김
  └ 깎고, 쓰러지면 무덤으로   ← 카드 처리에 남김
```

뒤의 것은 암흑 화염만의 일이 아니다. **맞는 모든 경우에 같다.** 통째로 옮겼으면 그
공통 부분이 상태 규칙 쪽에 들어가고, 다음에 새 상태가 생길 때 같은 것을 또 쓰게 된다.
