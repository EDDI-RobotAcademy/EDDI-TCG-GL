# Issue

1. 파일을 쪼개고 싶었지만 쪼개면 안 됐다
    - 증상
        - 갈래 셋이 서로 안 겹치니 파일 셋으로 나누는 것이 자연스러워 보였다
    - 원인
        - 상태 넷(고른 것 없음 / 유닛을 집었다 / 패널이 열렸다 / 대상을 고르는 중)이 갈래 셋을 가로지른다
        - 패널을 닫으면 상태가 [유닛을 집었다] 로 돌아가고, 대상을 고르고 나면 [고른 것 없음] 이 된다. 결과를 다 그린 뒤에도 상태를 되돌린다
        - 쪼개면 그 상태를 누가 드는지가 다시 문제가 된다. R2-124 에서 열두 군데에 흩어져 있던 것을 한 곳으로 모은 것이다
    - 처리
        - 적는 자리만 나누고 파일은 하나로 두었다. 왜 안 쪼갰는지를 파일 맨 위에 적었다
        - **겹치지 않는다는 것이 곧 나눠도 된다는 뜻은 아니다.** 가로지르는 것이 있는지 먼저 본다

## 왜 파일은 그대로인가

상태 넷이 갈래 셋을 가로지른다.

```
패널을 닫는다        → 상태가 [유닛을 집었다] 로 돌아간다
대상을 고른다        → 상태가 [고른 것 없음] 이 된다
결과를 다 그린다     → 상태를 되돌린다
```

상태를 한 곳이 들어야 이 흐름이 한 자리에서 보인다. R2-124 가 열두 군데에 흩어져 있던
상태 옮기기를 한 곳으로 모은 일이었고, 쪼개면 그것을 되돌리는 셈이 된다.
