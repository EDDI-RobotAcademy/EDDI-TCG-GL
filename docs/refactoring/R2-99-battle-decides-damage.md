# [ETWGL-R2-99] 피해량을 화면이 아니라 전투 상태가 정한다

선행: R2-98 │ 후행: R2-100 │ 산출물: 사용자가 고른 것을 담는 명령 │ Type: Rule │ Domain: Battle

# Success criteria

1. 왜 하는지와 어디까지 할지를 정한다
    - 문제
        - 명령 넷이 피해량을 담고 있다. 화면이 계산해서 실어 보낸다
        - 사용자가 한 일은 [이 유닛으로 저 유닛을 친다] 이지 [30 만큼 친다] 가 아니다
        - 광역기일 때 어느 명령을 보낼지도 화면이 정한다. 본체까지 가는지를 화면이 판단한다
        - R2-98 로 전투가 카드에 적힌 값을 읽을 수 있게 됐으므로 이제 뺄 수 있다
    - 목적
        - 명령은 사용자가 고른 것만 담고, 얼마나 아픈지는 전투가 정한다
    - 기대 결과
        - 카드가 늘어도 [이 카드는 얼마] 가 화면에 안 쌓인다
    - 건드리지 않는 것
        - 사용자가 고르는 것 - 덱에서 고른 카드, 붙일 종족, 섞는 씨앗은 그대로 명령에 담는다
        - 연출 - 어느 연출을 트는지는 화면 일이다

2. 명령이 담은 것 중 무엇이 계산된 값인지 가른다
    - 사용자가 고른 것과 전투가 정할 수 있는 것을 나눈다

3. 피해량 대신 무엇을 담아야 하는지 정한다
    - 전투가 피해량을 내려면 무엇이 필요한지 본다

4. 화면이 정하던 다른 것도 함께 본다
    - 어느 명령을 보낼지 고르는 것도 판단이다

5. 게임 동작이 달라지지 않았는지 확인한다
    - 일반 공격, 단일기, 광역기, 본체 공격

# Issue

1. 광역기 명령이 둘이었던 이유가 카드 데이터였다
    - 증상
        - [상대 유닛 전부] 와 [상대 유닛 전부와 본체] 두 명령이 따로 있었다
        - 화면이 카드의 범위를 보고 둘 중 하나를 골라 보냈다
    - 원인
        - 전투가 범위를 몰랐을 때는 화면이 알려 줄 수밖에 없었다
        - 처리기 안에서는 둘이 같은 함수를 부르고 [본체까지 가는가] 한 값만 달랐다
    - 처리
        - 하나로 합쳤다. 본체까지 가는지는 카드에 적힌 범위에서 전투가 정한다
        - R2-7 의 기준으로 대 봤다. 둘은 카드마다 갈리는 것이 아니라 **한 가지 일이 카드 값에
          따라 달라지는 것** 이다. 갈릴 이유가 카드 데이터에 있으므로 명령을 나눌 이유가 없다
        - **명령이 여럿인 이유가 카드 값이라면 명령이 아니라 값으로 갈라야 한다**

2. 피해량을 내는 것을 밖에 열어 두면 다시 새는 길이 된다
    - 증상
        - R2-98 에서 [얼마나 아픈가] 를 전투에 만들고 화면이 그것을 불러 명령에 실었다
        - 물어봐서 받은 답을 다시 실어 보내는 꼴이었다
    - 원인
        - 전투에 옮겨 놓고도 밖에서 부를 수 있게 열어 두었다
    - 처리
        - 화면이 안 쓰게 된 뒤 밖에서 못 부르게 닫았다
        - **옮긴 것을 밖에 열어 두면 옮기기 전과 같은 길이 남는다. 안 쓰게 되면 닫는다**

3. 로그가 값에 매달려 있었다
    - 증상
        - 피해량을 빼려 하니 로그 두 줄이 그 값을 쓰고 있었다
    - 원인
        - 무엇을 눌렀는지가 아니라 그 결과 숫자를 찍고 있었다
    - 처리
        - 무엇을 눌렀는지를 찍게 했다. 실제 체력 변화는 일어난 일에 전후 값이 이미 담겨 있다
        - **로그가 값을 붙들고 있으면 그 값이 정말 필요한지 다시 본다**

## 명령이 어떻게 바뀌었나

| 전 | 후 |
| --- | --- |
| `attackUnit { 공격자, 대상, 피해량 }` | `attackUnit { 공격자, 대상, 고른 것 }` |
| `attackOpponentMaster { 공격자, 피해량 }` | `attackOpponentMaster { 공격자, 고른 것 }` |
| `attackEveryOpponentUnit { 공격자, 피해량 }` | 없앰 |
| `attackEveryOpponent { 공격자, 피해량 }` | `attackEveryOpponent { 공격자, 고른 것 }` |

[고른 것] 은 일반 공격이거나 스킬 하나다. 사용자가 액티브 패널에서 누른 것 그대로다.

## 화면이 아직 전투에 묻는 것

| 무엇 | 왜 묻는가 |
| --- | --- |
| 누구를 치는가 | 대상을 골라야 하는 공격인지 여기서 갈린다. 광역기면 바로 나가고 단일기면 대상을 기다린다 |
| 스킬 비용 | 안내 문구에 쓴다 |
| 에너지가 모자란가 | 막고 안내 문구를 띄운다 |

셋 다 **묻고 화면이 자기 일에 쓴다.** 물어서 받은 답을 명령에 다시 실어 보내지 않는다.
