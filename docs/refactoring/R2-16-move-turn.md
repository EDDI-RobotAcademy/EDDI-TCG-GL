# Issue

1. 턴에 관한 것 하나가 common 아래에 있었다
    - 증상
        - 턴 표시 코드가 src/common/turn/ 에 있었다. common 은 여러 화면이 함께 쓰는 것을 두는 자리다
    - 원인
        - 실제로 쓰는 곳을 세어보니 전투 화면과 전투 시나리오뿐이었다. 로비, 상점, 보유 카드 어디에도 턴이 없다
        - 이름이 일반적이면 common 에 두게 된다. turn 은 일반적인 말이지만 이 게임에서는 전투에만 있다
    - 처리
        - battle/turn/hud/ 로 옮겼다
        - **common 에 둘지 정할 때 이름의 일반성이 아니라 쓰는 곳을 센다**

2. 본편과 시나리오가 서로 다른 턴 코드를 쓰고 있었다
    - 증상
        - 본편은 옛 표시 함수 showTurn() 을, 시나리오는 새 표시 코드 TurnHudRendererV2 를 쓴다
        - 같은 화면을 만드는 코드가 두 벌이다
    - 원인
        - 새 방식으로 만들면서 본편을 갈아끼우지 않았다
    - 처리
        - 두 벌을 같은 폴더에 나란히 두었다. 합치는 것은 화면이 달라질 수 있어 이번 범위 밖이다
        - **갈아끼우지 않은 두 벌은 붙여 둔다.** 떨어져 있으면 하나만 고치게 된다
