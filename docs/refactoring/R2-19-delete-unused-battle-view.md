# Issue

1. 이름으로 세다가 로그 문구를 사용처로 셌다
    - 증상
        - 안 쓰는 화면을 [시나리오 열한 개가 쓴다] 고 봤다
        - 실제로는 시나리오들이 각자 만든 다른 클래스가 같은 로그 문구를 베껴 갖고 있었다
    - 원인
        - 규칙 17 에 [이름으로 센다] 를 적어놓고, 이름이 문자열 안에 있는 경우를 가려내지 않았다
        - 이 저장소는 화면 파일을 복사해서 만든 흔적이 많아 로그 문구가 그대로 남아 있다
    - 처리
        - import 만으로 다시 셌다. 한 곳도 없었다
        - **이름이 나온다고 쓰는 것이 아니다.** import 인지 문자열인지 가른다

2. 전체가 주석 처리된 파일이 폴더 하나를 차지하고 있었다
    - 증상
        - 전투 화면 그리기 조종 파일 28줄이 전부 // 로 시작한다. 클래스 선언조차 없다
        - 타입 검사에 안 걸리고 의존 검사에도 안 걸린다. 아무 도구도 이것을 잡지 못한다
    - 원인
        - 지우지 않고 주석 처리해 두었다
    - 처리
        - 지웠다. 폴더도 함께 없어졌다
        - **주석 처리한 코드는 도구가 못 잡는다.** 폴더 목록을 훑을 때만 눈에 띈다
