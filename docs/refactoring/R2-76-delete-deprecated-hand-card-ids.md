# Issue

1. 티켓이 시킨 일이 이미 없었다
    - 증상
        - 티켓은 [확인용 화면 다섯이 새 방식으로 읽게 한다] 였는데 읽는 곳이 없었다
        - 다섯 화면이 가져오기만 하고 안 썼다
    - 원인
        - R2-24 에서 판정할 때 가져오는 곳으로 셌다. 부르는 곳은 안 셌다
    - 처리
        - 새 방식으로 바꾸는 대신 그냥 지웠다
        - **가져오는 것과 부르는 것은 다르다.** 셀 때 무엇을 세는지 정한다

2. 낡은 저장소 셋의 처지가 서로 달랐다
    - 증상
        - 셋이 같은 폴더에 같은 표시로 있어서 같은 처지처럼 보였다
    - 원인
        - 낡았다는 표시가 붙은 시점만 같고, 얼마나 쓰이는지는 각각이다
    - 처리
        - 카드 번호는 아무도 안 부르고, 카드 자리는 확인용 화면 넷이, 화면 덩어리는 본편 둘과 확인용 화면 열둘이 부른다
        - **같은 표시가 붙었다고 같은 처지가 아니다.** 하나씩 센다
