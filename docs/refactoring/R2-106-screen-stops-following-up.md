# Issue

1. 지운 것이 전부 아무도 안 부르는 것이었다
    - 증상
        - 두 함수를 지우려고 부르는 자리를 찾았는데, 부르는 자리가 하나도 없었다
    - 원인
        - 규칙을 전투로 옮길 때 부르는 자리를 새 것으로 바꿨다
        - 그 자리가 마지막 하나였는데, 원래 함수를 안 지웠다
    - 처리
        - 지웠다. 게임 동작은 안 바뀐다
        - **옮긴 일이 끝나면 원래 자리가 비었는지 그 자리에서 확인한다. 나중에 찾으면 다른 이름으로 보인다**

2. 남아 있었다면 무덤에 같은 카드가 두 장 들어갔다
    - 증상
        - 화면의 것과 전투의 것이 둘 다 [무덤으로 보낸다] 였다
        - 둘 다 불렸으면 한 장을 쓰고 무덤에 두 장이 생긴다
    - 원인
        - 옮길 때 새 자리를 만들고 원래 자리를 안 지웠다
    - 처리
        - 실제로는 아무도 안 불러서 안 터졌다. 하지만 다음에 이 화면에 손대는 사람이 둘 중 하나를 고르게 된다
        - **같은 일을 하는 것이 둘 있는 것은, 지금 안 터져도 고쳐야 할 것이다**

3. 앞 문서에 적은 숫자가 틀렸다
    - 증상
        - R2-105 문서에 [열다섯 중 여덟이 판 차리기] 라고 적었다. 세어 보니 열이었다
    - 원인
        - 찾은 결과를 그대로 셌는데, 그중 하나는 주석 안의 글자였다
        - 판 차리기와 규칙을 가르는 것도 눈으로만 했다
    - 처리
        - 이 문서에 바른 숫자를 적었다
        - **찾은 줄 수를 그대로 세지 않는다. 주석에 같은 글자가 들어 있다**

## 남은 열 곳

| 무엇 | 왜 화면에 있나 |
| --- | --- |
| 시작 필드 에너지, 상대 시작 필드 에너지 | 실제 대전에서는 서버가 준다 |
| 내 덱, 상대 덱 | 실제 대전에서는 서버가 준다 |
| 시작 손패 | 실제 대전에서는 뽑기로 채운다 |

| 무덤 둘, 로스트 존 둘의 시험용 카드 | 페이지 넘기기를 확인하려고 채워 둔 것 |
