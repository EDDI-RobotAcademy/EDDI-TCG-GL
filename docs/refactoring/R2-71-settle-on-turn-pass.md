# [ETWGL-R2-71] 턴이 넘어갈 때 유닛에 붙은 것을 전투 상태가 정산한다

선행: R2-70 │ 후행: R2-72 │ 산출물: 턴 넘김이 명령이 되고 정산이 그 안에서 끝난다 │ Type: Rule │ Domain: Battle Unit

# Success criteria

1. 왜 하는지와 어디까지 할지를 정한다
    - 문제
        - 턴이 넘어갈 때 일어나는 일을 화면이 조립한다
        - 암흑 화염으로 깎고, 죽으면 무덤에 넣고, 빙결을 풀고, 한 장 뽑는 것을 화면이 순서대로 부른다
        - 그 사이에 화면이 닫히면 턴은 넘어갔는데 화염 정산은 안 된 상태가 된다
    - 목적
        - 턴을 넘기는 일 하나를 전투가 받아 끝까지 처리하게 한다
    - 기대 결과
        - 화면은 넘기라고만 하고 돌려받은 것으로 그린다
    - 건드리지 않는 것
        - 모래시계, 안내 문구, 턴 표시 - 화면이다
        - 네더 블레이드 매 턴 패시브 - 값으로 안 되는 넷의 하나다

2. 두 방향이 하는 일이 다른 것을 확인한다
    - 내 턴을 끝낼 때는 암흑 화염이 정산된다. 상대 턴이 시작되는 시점이다
    - 내 차례로 돌아올 때는 턴이 오르고, 에너지가 늘고, 빙결이 풀리고, 한 장 뽑는다
    - 빙결은 상대 턴 내내 유지되어야 하므로 푸는 시점이 화염과 다르다

3. 뽑는 일을 턴 넘김 안으로 넣는다
    - 지금은 화면이 턴을 넘긴 뒤에 따로 뽑으라고 시킨다
    - 턴이 시작되면 뽑는 것이 규칙이다. 한 자리에서 끝나야 한다

4. 화면에 무엇을 남길지 정한다
    - 쓰러진 것을 감추고 자리를 다시 잡는 일
    - 얼음 표시를 걷는 일
    - 뽑은 카드를 손패에 붙이는 일

5. 게임 동작이 달라지지 않았는지 확인한다
    - 턴 종료, 암흑 화염, 빙결 해제

# Issue

1. 뽑는 일이 턴 넘김 밖에 있었다
    - 증상
        - 화면이 턴을 넘기고 나서 따로 [한 장 뽑아라] 를 보내고 있었다
    - 원인
        - 뽑기를 명령으로 만들 때 사용자가 직접 뽑는 것만 봤다. 턴이 시작되면 저절로 뽑는 것도 있다
    - 처리
        - 턴 넘김 안으로 넣었다. 뽑는 규칙 자체는 한 곳에 그대로 있다
        - **저절로 일어나는 일은 그것을 일으킨 행동 안에서 끝난다.** 밖에서 이어 붙이면 사이가 생긴다

2. 두 방향의 정산 시점이 다르다
    - 증상
        - 암흑 화염은 내 턴을 끝낼 때, 빙결은 내 차례로 돌아올 때 정산한다
    - 원인
        - 빙결은 상대의 행동을 막는 것이라 상대 턴 내내 유지되어야 한다
        - 암흑 화염은 상대 턴이 시작될 때 타는 것이다
    - 처리
        - 두 방향을 각각 명령으로 만들고 하는 일을 따로 적었다
        - **한 낱말로 [턴이 넘어간다] 라고 해도 방향마다 일어나는 일이 다르다**

3. 안 쓰게 된 함수를 그 자리에서 지웠다
    - 증상
        - 정산을 전투로 옮기니 화면의 함수 둘이 아무도 안 부르게 됐다. 43줄이다
    - 원인
        - 옮기면 옛 길이 남는다
    - 처리
        - 같은 티켓에서 지웠다. 남겨 두면 다음에 여는 사람이 어느 쪽이 진짜인지 모른다
        - **옮긴 뒤 안 쓰게 된 것은 그 자리에서 지운다**
