# [ETWGL-R2-61] 필드 유닛의 체력과 살아 있는 순서를 전투 상태 안으로 옮긴다

선행: R2-60 │ 후행: R2-62 │ 산출물: FieldCard 가 체력과 붙은 에너지를 든다 │ Type: Rule │ Domain: Battle Field

# Success criteria

1. 왜 하는지와 어디까지 할지를 정한다
    - 문제
        - 상대 유닛의 체력과 붙은 에너지를 확인용 화면이 지도 둘로 따로 들고 있다
        - 살아 있는 차례도 배열 하나로 따로 들고 있다
        - 그런데 전투는 이미 상대 필드 목록을 들고 있다. 같은 것을 두 군데에 나눠 든 것이다
    - 목적
        - 유닛의 상태와 순서를 전투가 든 필드 목록 하나로 모은다
    - 기대 결과
        - 전투를 통째로 적으면 유닛의 체력과 붙은 에너지도 함께 적힌다
        - 유닛이 쓰러지면 목록에서 빠지고 뒤엣것이 당겨진다
    - 건드리지 않는 것
        - 내 필드에 놓은 유닛의 체력 - 이 화면은 아직 안 쓴다
        - 유닛을 그리는 것 - 화면이다

2. 살아 있는 차례가 무엇인지 확인한다
    - 배열이 담고 있던 것은 [지금 살아 있는 유닛이 어떤 차례로 서 있는가] 다
    - 전투가 든 필드 목록이 이미 그것이다. 새로 만들 것이 없다
    - 유닛이 쓰러지는 것은 목록에서 빠지는 것이다

3. 필드 카드가 무엇을 더 들어야 하는지 정한다
    - 체력과 붙은 에너지다. 필드에 서 있는 동안의 상태다
    - 손패에 있을 때는 뜻이 없으므로 손패 카드에는 안 붙인다
    - 체력은 0 아래로 안 내려간다. 그 규칙도 함께 든다

4. 쓰던 곳을 바꾼다
    - 체력을 읽고 쓰는 곳, 에너지를 읽고 쓰는 곳, 차례를 보는 곳
    - 유닛을 목록에서 빼는 곳이 열 군데다

5. 게임 동작이 달라지지 않았는지 확인한다
    - 상대 유닛 쓰러뜨리기, 정렬, 카드 효과
    - 가운데 것이 빠질 때와 여럿이 한 번에 빠질 때

# Issue

1. 이미 있는 것을 또 만들어 놓고 있었다
    - 증상
        - 살아 있는 차례를 배열로 따로 들고 있었다. 전투는 이미 상대 필드 목록을 들고 있었다
    - 원인
        - 그 화면이 전투에 상대 유닛을 안 넣고 있었다. 전투가 든 목록이 비어 있어서 쓸 수 없었다
    - 처리
        - 전투에 넣고 나니 배열이 통째로 필요 없어졌다
        - **담을 곳이 비어 있으면 사람은 옆에 하나 더 만든다.** 옮길 때는 담을 곳부터 채운다

2. 유닛이 쓰러지는 일이 두 줄이었다
    - 증상
        - 무덤으로 보내는 줄과 차례에서 빼는 줄이 늘 붙어 다녔다. 열 군데다
    - 원인
        - 담는 곳이 둘이라 두 곳을 다 고쳐야 했다
    - 처리
        - 차례에서 빼는 것이 전투에서 빼는 것이 됐다
        - **늘 붙어 다니는 두 줄은 원래 한 줄이었을 수 있다**

3. 체력을 손패 카드에는 안 붙였다
    - 증상
        - 손패 카드와 필드 카드가 같은 모양이라 양쪽에 붙이고 싶어진다
    - 원인
        - 두 카드가 담는 것이 거의 같다
    - 처리
        - 필드에만 붙였다. 손패에 있는 카드에 체력이 몇 남았는지는 뜻이 없다
        - **같은 모양이어도 뜻이 없는 자리에는 안 붙인다**
