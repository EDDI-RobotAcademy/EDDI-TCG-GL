# [ETWGL-R2-69] 필드 에너지를 유닛에 붙이는 일을 전투 상태가 처리한다

선행: R2-68 │ 후행: R2-70 │ 산출물: 화면이 전투를 직접 고치는 곳이 준다 │ Type: Rule │ Domain: Battle Energy

# Success criteria

1. 왜 하는지와 어디까지 할지를 정한다
    - 문제
        - 카드를 옮기고 나서도 화면이 전투를 직접 고치는 곳이 스무 군데 남아 있다
        - 카드에 붙은 에너지는 전투와 화면 두 곳에 산다. 스킬 비용이 화면 것을 읽는다
        - 필드 에너지를 유닛에 붙이는 것은 카드가 아닌 사용자 행동인데 명령이 없다
    - 목적
        - 남은 것을 세어 무엇이 왜 남았는지 가르고, 카드가 아닌 것을 정리한다
    - 기대 결과
        - 화면이 전투를 직접 고치는 곳이 시작 채우기와 아직 안 옮긴 카드의 것만 남는다
    - 건드리지 않는 것
        - 값으로 안 되는 카드 넷 - R2-87 에서 모양을 정한 뒤에 본다
        - 시작 채우기 - 서버가 생기면 서버가 준다. 지금 형태가 맞다

2. 남은 것을 세어 무엇이 왜 남았는지 가른다
    - 시작 채우기인가, 아직 안 옮긴 카드의 것인가, 그 밖인가
    - 그 밖인 것만 이번에 다룬다

3. 카드가 아닌 사용자 행동을 명령으로 만든다
    - 필드 에너지를 유닛에 붙이는 일이다
    - 쓸 수 있는지 보고, 깎고, 붙이는 것을 전투가 한다

4. 두 곳에 살던 값을 한 곳으로 모은다
    - 카드에 붙은 에너지를 화면이 따로 세고 있었다
    - 스킬 비용을 보는 쪽이 전투 것을 읽게 하면 화면 것을 지울 수 있다

5. 게임 동작이 달라지지 않았는지 확인한다
    - 필드 에너지를 카드에 붙이기, 스킬 쓰기

# Issue

1. 카드가 아닌 사용자 행동이 하나 숨어 있었다
    - 증상
        - 필드 에너지를 유닛에 붙이는 일이 명령이 없었다. 화면이 직접 깎고 붙였다
    - 원인
        - R2-64 에서 사용자가 하는 일을 여덟으로 셀 때 이것을 빠뜨렸다
        - 카드를 쓰는 것만 보고 셌는데 이건 카드가 아니다
    - 처리
        - 명령을 하나 더 만들었다
        - **사용자가 하는 일을 셀 때 카드만 보면 안 된다.** 카드 없이 하는 것도 있다

2. 값이 두 곳에 사는 것을 이번에 없앴다
    - 증상
        - 카드에 붙은 에너지를 전투와 화면 양쪽에 넣고 있었다. R2-68 에서 적어 둔 것이다
    - 원인
        - 스킬 비용을 보는 쪽이 화면 것을 읽어서 한쪽만 채우면 스킬이 안 나갔다
    - 처리
        - 비용을 보는 쪽이 전투 것을 읽게 하고 화면 것을 지웠다
        - **두 곳에 사는 값은 읽는 쪽을 먼저 옮긴다.** 쓰는 쪽만 옮기면 읽는 쪽이 안 따라온다

3. 남은 것이 왜 남았는지를 세어 갈랐다
    - 증상
        - 화면이 전투를 직접 고치는 곳이 열넷 남았다. 다 나쁜 것처럼 보인다
    - 원인
        - 남은 것을 개수로만 보면 무엇이 문제인지 알 수 없다
    - 처리
        - 시작 채우기 여섯, 아직 안 옮긴 카드의 것 여섯, 안 쓰는 것 하나로 갈랐다
        - 시작 채우기는 서버가 줄 것이라 지금 형태가 맞다
        - **남은 것을 셀 때는 왜 남았는지까지 함께 적는다.** 안 그러면 다 고칠 것처럼 보인다
