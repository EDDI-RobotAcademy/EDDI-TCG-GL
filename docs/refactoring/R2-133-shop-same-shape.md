# Issue

1. 비율을 받는 자리에 점 좌표가 들어가 있었다
    - 증상
        - 내 카드 누르는 자리가 화면 밖에 있었다. 눌러도 아무 일이 안 났다
    - 원인
        - 누르는 자리를 만드는 함수가 비율을 받는데, 한 곳은 비율(0.04761)을 넘기고 다른 곳은 점 좌표(-695)를 넘겼다
        - `(-695 - 0.5) × 창너비` 가 되어 화면 밖으로 갔다
        - 인자 이름이 `positionXPercent` 인데 막을 것이 없었다. 둘 다 number 다
    - 처리
        - 자리와 크기를 전부 비율로 적는 프레임으로 옮겼다. 섞일 자리가 없어졌다
        - **같은 종류의 숫자가 두 단위로 돌아다니면 언젠가 섞인다.** 이름에 단위를 적어 두는 것으로는 안 막힌다. 한 단위만 남기는 것으로 막는다

2. 안 보이는 것이 어긋나 있어도 눈에 안 띈다
    - 증상
        - 내 카드 자리가 화면 밖에 있었는데 아무도 몰랐다
    - 원인
        - 누르는 자리는 안 보인다. 그림은 배경에 그려져 있으니 글자는 제자리에 보인다
        - 글자는 보이고 누르는 자리만 엉뚱한 데 있으니, 눌러도 안 되는 것이 [아직 안 만든 기능] 처럼 보인다
    - 처리
        - 안 보이는 것도 같은 목록에 넣어 같이 다시 재게 했다
        - **안 보이는 것이 어긋나면 고장이 아니라 미완성으로 읽힌다.** 그래서 더 오래 남는다

## 왜 여섯 군데였나

상점은 누를 것이 두 종류다.

| | 무엇 | 그림 |
| --- | --- | --- |
| 뽑기 단추 넷 | 종족별 뽑기 | 그림 파일이 있다 |
| 누르는 자리 둘 | 로비, 내 카드 | **없다.** 글자가 배경에 함께 그려져 있다 |

둘이 다르게 생겼다고 만들기·누름·크기 조절을 각각 두 벌 두었다. 실제로 다른 것은
**그림이 있는지** 하나뿐이다. 그 하나를 값으로 두니 나머지가 한 벌이 됐다.

```
{type: DrawUndead, imageSrc: 'draw_undead.png', ...}
{type: ToLobby,    imageSrc: null,              ...}   ← 안 보이지만 광선에는 걸린다
```
