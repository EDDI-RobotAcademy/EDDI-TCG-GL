# Issue

1. 경로를 다시 계산하는 도구를 만들었는데 옛 위치를 잃어버렸다
    - 증상
        - 파일을 옮긴 뒤 경로를 고치게 했더니, 밖에서 부르는 27개는 고쳐졌는데 옮긴 파일들이 밖을 부르던 경로는 그대로였다
        - 타입 오류 스무 건 남짓이 났다
    - 원인
        - 파일을 먼저 옮기고 나서 폴더를 훑었다. 훑으면서 만난 것은 이미 새 위치라, 옛 위치가 어디였는지 알 수 없었다
        - 옛 위치를 알아야 그 파일이 적어둔 상대 경로를 풀 수 있다
    - 처리
        - 새 위치에서 옛 위치를 되짚는 표를 만들어 두 번째로 훑었다
        - **옮긴 파일의 경로를 고치려면 옛 위치를 들고 있어야 한다.** 옮기기 전에 표를 만들어 둔다

2. 계획표의 손패 다섯 폴더 중 셋이 손패 것이 아니었다
    - 증상
        - battle_field_card_scene 은 드래그, 마우스 놓기, 좌우 클릭, 키보드도 쓴다
        - battle_field_card_alignment 는 저장소 열두 개를 끌어쓰고 손패와 필드 양쪽을 정렬한다
    - 원인
        - 계획할 때 폴더 이름만 보고 카테고리를 정했다. 부르는 곳을 세지 않았다
    - 처리
        - 셋을 R2-41, R2-42 로 뺐다. 손패와 필드가 다 자리를 잡은 뒤에 옮긴다
        - **이름에 무엇이 없는지도 본다.** card_scene 은 이름에 hand 가 없는데 손패 묶음에 들어가 있었다

3. 이름만 deprecated 인 저장소가 살아서 돌고 있다
    - 증상
        - battle_field_hand/deprecated_repository/ 세 파일을 본편 두 곳과 시나리오 열세 곳이 쓴다
        - CLAUDE.md 에는 deprecated_ 폴더를 죽은 것으로 두고 확장하지 않는다고 되어 있다
    - 원인
        - 새것으로 갈아타면서 옛것을 지우지 않고 폴더 이름만 바꿨다
    - 처리
        - 옮기지 않고 옛 자리에 남겼다. 옮기면 새 폴더 안에 죽은 이름이 들어간다
        - R2-43 로 등록했다
        - **이름이 deprecated 라고 죽은 것이 아니다.** 부르는 곳을 세어 확인한다
